面包屑与标题由 route.meta 自动生成（骨架内置）；本页内容区由业务组件填充。

定位：admin-shell = 管理系统骨架，不是业务后台。 内置通用 chrome（主题 / 通知面板 / 用户下拉 / 面包屑 / 折叠侧栏 / 可选 ⌘K）， 业务只通过 defineAdminModule 挂子菜单与页面。

骨架内置（开箱）

  • 侧栏布局 + 折叠持久化
  • 顶栏：主题切换、通知铃铛、用户下拉
  • PageHero：面包屑 + 标题 + 描述
  • 可选 Command（⌘K）搜菜单
  • 路由 activeKey / menuKey 高亮

业务扩展（宿主填）

  • modules：菜单 + 路由（含子菜单）
  • user：姓名 / 头像 / 角色文案
  • notifications：列表数据或插槽
  • onLogout / 个人中心 path
  • router-view 内的业务页面
