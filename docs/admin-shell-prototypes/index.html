方案对比

方案 范式来源 适合场景 菜单深度 推荐度
A · Classic Sidebar shadcn-admin / dashboard-01 SaaS 控制台、通用中后台 2–3 级 默认推荐
B · Floating Inset shadcn sidebar floating 偏产品感、营销站+控制台同仓 2 级 体验优先
C · Icon Rail + Panel Linear / VS Code / Notion 模块多、需二级上下文面板 3 级+ 复杂后台
D · Top Nav + Side 企业双导航 / Ant Design Pro 变体 多产品切换、门户型后台 2 级 多产品

SCHEME A

Classic Sidebar

左侧固定侧栏（可折叠为图标）+ 顶栏 + 内容。最接近当前 EAdminLayout，改造成本最低，通用性最好。

打开 →

SCHEME B

Floating Inset

侧栏悬浮圆角 + 页面内边距。更现代、更「产品」，适合 cloud 类控制台；窄屏要额外适配。

打开 →

SCHEME C

Icon Rail + Panel

最左图标轨（一级模块）+ 二级树面板 + 内容。模块极多时最清晰，quant-admin 类数据/运营/系统分区很合适。

打开 →

SCHEME D

Top Primary + Side

顶栏一级产品/工作区切换，侧栏二级功能。适合多租户/多产品门户；单产品时略重。

通用壳应固定的 UI 契约（与方案无关）

  • · #logo 品牌区（可点回 defaultPath）
  • · 侧栏 menu 支持 group / children / 隐藏路由
  • · #header-extra 用户菜单 / 主题 / 通知
  • · PageHero 面包屑 + title + description（可关）
  • · 折叠态 持久化 + 图标轨
  • · Command 可选全局搜索（⌘K）
  • · content 仅 <router-view / 插槽>
  • · 不内置 鉴权、角色、业务 API
