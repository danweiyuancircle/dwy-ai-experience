# Remotion 技术讲解视频复刻指南

## 目标与边界

本指南用于复刻“白底 AI 插画信息图 + 代码演示 + 逐句字幕 + 二维运镜”的横屏技术讲解视频。

- 成片规格固定为 `1920 × 1080`、`16:9`、`30fps`。
- 配音文件由使用者提供，不纳入本指南。
- 使用者负责生成插画素材；Remotion 负责全部画面合成、图表、排版、字幕、运镜、转场、混音和 MP4 渲染。
- 不依赖剪映、Premiere、After Effects 等额外剪辑软件。
- 不在 AI 生成图中保留可读文字、代码、表格或品牌标识；此类内容统一由 Remotion 绘制，避免乱码和变形。

## 成片视觉结构

每个场景固定拆为三层，防止素材和字幕互相干扰：

```text
Background  白底、轻网格、低对比装饰
Content     插画、SVG 图表、代码录屏或代码窗口
Overlay     字幕、红箭头、荧光框、角标、转场遮罩
```

建议画面占比：

| 区域 | 推荐占比 | 约束 |
| --- | ---: | --- |
| 留白 | 55–65% | 保持轻量，不以背景纹理填满 |
| 主视觉图形 | 25–35% | 单镜头只突出一个主要对象 |
| 说明文字与标签 | 8–12% | 由 Remotion 渲染，避免写入 AI 图片 |
| 强调色 | 不超过 10% | 只用于分类、箭头和关键词 |

## 视觉系统

### 色彩

```text
背景      #F7F7F4
描边      #263238
正文      #333333
青蓝      #2D9CDB
黄色      #F2C94C
红色      #EB5757
紫色      #9B51E0
```

- 背景保持近白色，不使用纯白与高饱和渐变。
- 所有插画物件采用深灰粗描边；文字采用深灰，避免纯黑带来的生硬感。
- 每一场景只使用一个主强调色；红色仅用于警告、对比和箭头。

### 字体与字幕

- 中文使用思源黑体、HarmonyOS Sans SC 或项目已确认的可商用无衬线字体。
- 字幕置于底部安全区，距底边 `90–120px`。
- 字幕最多两行；单行建议不超过 18 个中文字符。
- 字幕为白字深灰描边或深灰底浅色字；关键词单独使用青蓝、黄色或红色。
- 字幕按语义短句出现，而非按逐字滚动。

## AI 素材生成规范

### 资源清单

| 素材 | 生成方式 | 最小尺寸 | 约束 |
| --- | --- | --- | --- |
| 固定角色 | 正面或 3/4 侧半身/全身，透明背景 | `1600 × 1600` | 固定服装、发型、描边和配色 |
| 主物件 | K3、数据库、电脑、机器人等单对象透明图 | `1600 × 1600` | 每个对象单独出图，不合并成场景 |
| 信息图部件 | 文件、索引、箭头、数据块、容器 | `1200 × 1200` | 一个文件只放一个可独立运动的部件 |
| 背景 | 极浅灰白的简洁背景 | `1920 × 1080` | 不含文字和主体插画 |
| 代码演示 | 真实录屏，或由 HTML/CSS 重绘 | `1920 × 1080` | 不把焦点框、箭头或字幕烧录进去 |

### 通用提示词

```text
flat 2D technical explainer illustration, clean white background,
soft low-saturation palette, thick dark charcoal outline,
cute developer mascot, simple geometric shapes,
subtle grain, editorial infographic style, clean vector-like edges,
no text, no letters, no logo, no watermark, isolated subject
```

### 一致性约束

1. 首先生成并选定一张“角色设定母图”。后续角色图均携带该图作为参考图。
2. 固定人物服装、发色、肤色、线条粗细、眼睛比例和主色，不在单个镜头重新设计角色。
3. 生成透明背景 PNG；若模型不支持透明背景，生成纯白背景后再去背。
4. 技术概念通过物体组合表达，不依赖模型生成文字。例如数据库、索引、箭头和文件图标分别生成，再在 Remotion 中组合。
5. 生成时预留周边留白，避免物件贴边导致运镜放大后被裁切。

## 场景配比与节奏

```text
25%  白底信息图：角色 + 主物件 + 箭头 + 标签
55%  代码/终端：录屏或重绘窗口 + 局部聚焦 + 讲解字幕
15%  对比图/流程图：React、CSS、SVG 和图标库绘制
 5%  收束页：角色 + 结论 + 行动提示
```

- 信息图单场时长：`4–8 秒`。
- 代码讲解单场时长：`10–25 秒`。
- 只在新的信息单元出现时切场，不为制造节奏无意义跳切。

## Remotion 二维虚拟运镜

### 原则

每一场景以单个 `Camera` 容器承载内容层。运镜只改变该容器的 `scale`、`translateX`、`translateY` 和极小 `rotate`，而不是分别移动每一张素材。

- 每个镜头只保留一种主要运动：推近、平移、拉远三选一。
- 常规推近范围：`1.00 → 1.06–1.10`。
- 代码局部聚焦范围：`1.00 → 1.35–1.80`。
- 平移速度不超过每秒画宽的 `4%`。
- 常规镜头不旋转；卡片强调时最大旋转范围为 `±2°`。
- 采用 `useCurrentFrame()`、`interpolate()` 和 `Easing` 驱动所有动画；不要使用 CSS `transition` 或 `animation`。

### 信息图镜头模板（5 秒）

| 时间 | 动作 |
| --- | --- |
| `0.0–0.5s` | 场景淡入，镜头从 `scale: 0.96` 到 `1.00` |
| `0.5–4.2s` | 缓慢推近，镜头从 `scale: 1.00` 到 `1.07` |
| `1.0–2.0s` | 主物件从下方弹入 |
| `2.0–3.2s` | 箭头、标签按信息顺序依次绘制 |
| `4.2–5.0s` | 保留完整画面，白色遮罩擦入下一场 |

### 代码讲解镜头模板（8–15 秒）

| 时间 | 动作 |
| --- | --- |
| `0.0–0.4s` | 代码窗口淡入 |
| `0.4–3.0s` | 镜头平移至要讲解的代码区域 |
| `3.0–5.0s` | 局部放大到 `1.35–1.65` |
| `5.0–7.0s` | 荧光框、红箭头和关键词字幕出现 |
| `7.0s` 后 | 回退至全局或直接以遮罩转入下一场 |

### 转场

- 普通转场时长：`0.35–0.50 秒`。
- 优先使用白色遮罩擦除、轻微缩放和同向位移。
- 转场开始时，上一个场景仍需保持内容完整；不要先把内容淡出再转场。
- 不使用复杂 3D 翻页、随机抖动或连续漂浮，避免削弱技术讲解的清晰度。

## 组件边界

将场景拆为独立 React 组件，并以 JSON 提供内容和时间轴。推荐的组件职责如下：

| 组件 | 职责 |
| --- | --- |
| `Camera` | 承载场景内容，依据关键帧执行二维虚拟运镜 |
| `Caption` | 根据字幕时间戳渲染逐句字幕和关键词强调 |
| `Annotation` | 绘制红箭头、荧光框、下划线和标签 |
| `Transition` | 管理场景之间的遮罩、擦除和缩放转场 |
| `InfoGraphicScene` | 编排角色、物件、箭头和说明标签 |
| `CodeDemoScene` | 编排录屏/代码窗口、局部聚焦和标注 |
| `FlowChartScene` | 通过 SVG/CSS 绘制流程图、对比图和数据结构图 |

## 数据驱动方式

素材路径、字幕、镜头关键帧和场景时长均放入 JSON。替换 JSON、插画和音频，即可批量产出同风格视频。

```text
assets/
  character/
  objects/
  backgrounds/
  recordings/
  audio/
data/
  scenes.json
  captions.json
src/
  scenes/
  components/
  Root.tsx
```

## 验收清单

- [ ] 所有输出均为 `1920 × 1080`、`30fps`。
- [ ] AI 图片不含可读文字、代码、表格或水印。
- [ ] 角色在每一个镜头中保持同一设定。
- [ ] 字幕不超过两行，且不遮挡核心讲解对象。
- [ ] 代码焦点缩放不超过 `1.80`，可读内容不被裁切。
- [ ] 每个镜头只有一种主运镜方式。
- [ ] 强调色面积不超过画面 `10%`。
- [ ] 每个转场开始时，上一个场景内容完整可见。
- [ ] 所有动画由 Remotion 帧驱动，未使用 CSS 动画或外部剪辑软件。
