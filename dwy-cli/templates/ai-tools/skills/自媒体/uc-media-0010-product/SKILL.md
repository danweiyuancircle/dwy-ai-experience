## 行为

1. **频道闸门**：无 profile 先写；有则复用（force：更新频道定位 / 重写受众）。  
2. **主题**：用户原话 / 0005 `picked` + **seed_links**；无主题 → 建议 0005 或一次要主题词。  
3. **竞品检索**（有 seed 先用再补；默认 B站+YouTube，按分发加短视频）。  
4. **AI 推荐地图（强制自动写满 §3）**  
   - 从竞品缺口、已烂点、频道边界、默认时长 **直接生成** 讲/不讲/分块  
   - **禁止**只分析不推荐；**禁止**空着 §3 等用户先填  
   - 推荐即写入终稿表；回复时摘要「推荐讲这 N 柱」  
5. 结论「不做」→ 池 `rejected`，可不写满地图或写「不制作」。  
6. 不编链接/播放量；不做口播/事实深库/design。

## 工作流

### 1. 频道 + 主题

锁定 channel-profile、主题词、seed_links。

### 2. 竞品（§1）

多 agent 并行 → 竞品表 + 做不做 + ★标题 + 差异化一句。

### 3. 差异化洞察（§2）

明确：避开什么、补什么、钩子与顺序——**作为 §3 推导依据**。

### 4. AI 推荐演讲地图（§3 · 自动）

| 输出 | 规则 |
|------|------|
| 内容柱 3～7 | 优先「竞品缺口 + 频道边界内」；每柱一句「为何要讲」链到 §2 |
| 不讲清单 | 竞品已烂 + 越界 + 时长装不下 |
| 分块 × 时长 | 对齐柱；合计默认 3–5′ 或 6–8′ |
| 标题/钩子 | 默认用 §1 ★，可微调 |

写完 §4 推荐说明（如何推出、置信、可改点）。

### 5. 交付

路径：`0010-product/产品卡-{主题}.md`  

回复（5～8 行）：

- 做不做 · 差异化一句  
- **推荐演讲地图：柱 1…N（各半句）· 总时长**  
- ★标题 · 路径  
- 「改 §3 即改地图；确认后进 **0030 按地图扩事实**」

`fast`：可把地图当已采纳继续 0030（除非用户当场改）。  
`standard`：`ready_for_confirm`，等人说确认或改 md。
