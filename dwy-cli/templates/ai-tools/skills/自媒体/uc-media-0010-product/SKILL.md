# uc-media-0010-product · 产品定义

开拍前**唯一**产品真源。合并原「本集定位 + 产品卡」：  
**目标群体 · 主题 · 分发 · 讲什么 / 不讲 · 各内容块时长**。

---

## 行为（本 skill 内聚）

1. **能自动的全部自动**：读用户一句话 + 本集已有文档；直接写满  
   `{work_dir}/0010-product/产品卡-{主题}.md`。  
2. **产出可改终稿**：摘要 + 路径；用户改 md 或回修订即可。  
3. **不确定不胡编**：无主题时 **一次** 要主题词；可逆默认标 `推断`；禁止虚构账号/粉丝/独家数据。  
4. **不写仓根频道档案**；不连环问卷。  
5. **不做竞品表**（→ 0020 topic）；不做口播/镜号/画风冻结。

## 主文档必含

| # | 块 | 内容 |
|---|-----|------|
| 1 | **主题** | 一句话产品定义 + 成功标准 |
| 2 | **目标群体** | 是谁 / 不是谁 / 表达红线 |
| 3 | **分发** | 主场 · 同分发 · 画幅 · 是否拆平台版 |
| 4 | **讲什么** | 必讲内容柱（可编号） |
| 5 | **不讲什么** | 边界表 + 原因 |
| 6 | **内容块 × 时长** | 每块名 + 约秒/约分 + 合计总时长 |
| 7 | **包装占位（薄）** | 标题/封面候选即可；**★ 定稿标题以 0020 竞品后为准** |
| 8 | **决策日志** | 推断 / 用户修订 |

### 默认可推断

| 项 | 默认 |
|----|------|
| 画幅 | 横屏 1920×1080 · 16:9 · 30fps |
| 多平台 | 同分发时 **全横屏、不拆竖屏版**（除非用户明说） |
| 时长 | 热词专讲常 3–5′；内容柱多则 6–8′ / 更长并标推断 |
| 语气 | 事实优先、并肩、类比；禁扫盲/保姆级/你要记住 |

### 推荐正文结构

```markdown
# 产品卡：{主题}

## 0. 一句话产品定义

## 6. 主线顺序（可选流程图）
## 7. 包装占位（薄）
## 8. 下游清单
## 9. 决策日志
```

## 工作流

1. 确保 `0010-product/` 存在  
2. 从用户原话填满上表；缺主题则一次追问  
3. 写盘 `产品卡-*.md`  
4. 回复：群体 · 主题 · 分发 · 必讲/不讲要点 · 总时长 · 路径
