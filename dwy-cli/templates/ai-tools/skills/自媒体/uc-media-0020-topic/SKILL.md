# uc-media-0020-topic · 选题竞品（多源检索）

**只做一件事：** 读懂 0010 产品定义后，**全网多 agent 搜竞品**，输出  
**做不做建议 · 竞品事实表 · 差异化讲法 · 标题/钩子建议**。

**禁止**重写目标群体 / 必讲·不讲 / 分块时长——那些以 0010 为准；若竞品强烈暗示要改范围，只写 **「建议回写 0010」**，不静默改定义。

**模板：** [`templates/选题.template.md`](./templates/选题.template.md)

---

## 行为（本 skill 内聚）

1. **必读上游** `0010-product/产品卡-*.md`（无则一次要主题+范围，并建议先补 0010）。  
2. **多 agent / 多平台并行检索**（能并行则并行）：按 0010 **分发清单**决定平台；默认至少 **B 站 + YouTube**；0010 写了抖音/小红书则一并检索。  
3. **直接写满** `{work_dir}/0020-topic/选题-{主题}.md`。  
4. **不编数据**：播放量/排名 **未取到就写「未取到」**；链接必须真实或标失败原因。  
5. **差异化 = 讲法与包装**，服从 0010 内容柱与边界。

## 工作流程

### 1. 锁定输入（只读 0010）

从产品卡摘进选题文首（引用，不扩写）：

- 主题 / 一句话定义  
- 目标群体  
- 分发与画幅  
- **讲什么 / 不讲什么**  
- **内容块与时长合计**  

若 0010 缺失关键块 → 停或极简补问，不瞎编范围。

### 2. 多 agent 平台检索（不可跳过）

| 优先级 | 平台 | 规则 |
|--------|------|------|
| P0 | **B 站** | 中文主场；同题/近题 ≥2 条或标无结果 |
| P0 | **YouTube** | 机制/全球向；≥1～2 条或标跳过原因 |
| 按 0010 | 抖音 / 小红书 / 其他 | 0010 分发含则检索；**仍按 0010 画幅假设**（全横屏则不强迫竖屏拆版结论） |

**并行建议：** agent-A B站 · agent-B YouTube · agent-C 短视频平台（若需要）→ 主代理合成一张表。

**每条竞品字段：** 平台 · 标题/作者 · **真实链接** · 时长/体量 · 卖点 · 结构骨架 · 与 0010 重叠点 · 可借鉴 · 缺口。

维度：同题竞品 · 相邻爆款 · 缺口信号。

### 3. 建议与差异化讲法（核心产出）

在 **不推翻 0010 必讲/不讲** 的前提下写：

| 块 | 要求 |
|----|------|
| **供给判断** | 红海/可做/蓝一点；风险 |
| **差异化讲法** | 可执行：顺序、类比、贴图策略、钩子角度；对齐 0010 内容柱 |
| **建议微调** | 仅讲法；若需加/砍大块 → `建议回写 0010：…` |
| **标题 3～5** | ★ 一个；禁说教腔 |
| **钩子 ×3** | 开场 3 秒级 |
| **封面主副字** | 各一句 |

**不要**再输出第二套「目标读者/不讲清单」当终稿；最多「沿用 0010」一行。

### 4. 交付

路径：`{work_dir}/0020-topic/选题-{主题}.md`  

回复：做不做 · 竞品 3 要点 · 差异化一句 · ★标题 · 是否建议回写 0010 · 路径。
