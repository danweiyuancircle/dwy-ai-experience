# uc-media-comic-kit · 漫画科普表达 Kit

你是**漫画表达约束官**：规定这一风格怎么拆层、怎么生图、怎么排字、怎么保事实。  
不写选题长文；事实来源交给 0040/元素稿，本 kit **强制引用事实、禁止乱编名词与 Logo**。

## 行为（本 skill 内聚）

1. **能自动的全部自动**：给定镜号/元素意图/design，直接输出三层 BOM、关键词表、生图约束与自检。  
2. **产出可改终稿**：拆层表与 prompt 约束交给用户改；不逐步问「要不要 cloud」。  
3. **不确定不胡编**：专名/全称/Logo 无 0040 或官方源 → 标待核、贴纸先不写；**禁止**假 Logo、假术语、假数据（见 C-05/C-08）。

| Skill | 关系 |
|-------|------|
| `uc-media-0040-script` | 元素稿按本 kit **拆层 + 关键词表**；标注勿贴底 |
| `uc-media-0050-design` | style 选 comic 时启用本 kit |
| `uc-media-0060-assets` | 生图遵守 **简洁/渐进/事实**、分层铁律、**字幕安全区** |
| `uc-media-0090-remotion` | 贴片 **enter_order**；字用贴纸组件；**底边不放关键信息** |
| 工程 | `remotion-friendly/src/components/ComicKit.tsx` |

**可单独执行**：约束某一镜/章的漫画拆法；不依赖 flow。

## 0. 风格一句话

> **纸面漫画科普**：底图稳住；内容小块渐进往上贴；字也是贴纸；**屏上关键词与品牌必须基于事实**；排版宁可少、不可挤。

同义：`comic-explainer` · `friendly-explainer` · 友好图解动画。  
**不是**：深色 HUD、纯字卡、full_composite 完成帧、写实摄影、假 Logo/假术语。

## 1. 三层模型（强制）

```text
① base_bg     底图（章可换 / 可全片共用）—— 章内通常不动或极慢 Ken Burns
② content     内容小块（卡、角色、道具、节点）—— 按 enter_order 往上加
③ text_sticker 贴纸字（胶带/云朵/爆炸贴）—— 跟内容或口播出现，禁止大段纯系统字
```

| 层 | 变什么 | 不变什么 |
|----|--------|----------|
| 底图 | 换章可换皮；同章尽量稳 | 不把「会依次出现」的零件画死在底图上 |
| 内容 | 一小块一小块加 | 一镜一主新增（或一小批相关块） |
| 贴纸字 | 短句、关键词 | 不写长段落说明书 |

### 1.1 禁止

| ID | 禁止项 |
|----|--------|
| C-01 | **`full_composite`**：底图+全部内容+全部字一次生成的「完成帧」当主交付 |
| C-02 | 用整图 fade 假装「逐个贴上」 |
| C-03 | **纯 UI 字**：无描边/无贴纸形的大号系统字体当主文案 |
| C-04 | 一屏同时砸 ≥4 个无关主内容块（信息过载） |
| C-05 | AI 从零生成品牌 Logo / 假吉祥物当真标 |
| C-06 | 贴纸字过长不拆：中文主贴 **>16 字** 仍单贴硬塞 |
| C-07 | **挤版**：一屏同时塞满关键词 + 多主内容 + 长句（无渐进） |
| C-08 | **编造事实**：杜撰产品名、错写专业名词、乱造数据/全称 |
| C-09 | 生图时在插画里烤满说明文（应留给贴纸层 / 工程字） |
| C-10 | 同一镜出现互相矛盾的术语或与 0040/元素稿不一致的写法 |
| C-11 | **贴底挡字幕**：关键贴纸字 / 内容块 / 路线图节点压在 **字幕带** 内（见 §2.1） |
| C-12 | **硬拆完整短语**：把本应一体的片名/专名/短句拆成多枚贴纸只为「好看」（见 §2.0.1） |

### 1.2 必须

| ID | 必须项 |
|----|--------|
| M-01 | BOM：`base_bg` + `content[]` + `text_sticker[]` + `enter_order` |
| M-02 | 内容块分文件/组件；贴纸字可独立 PopIn |
| M-03 | 真 Logo：`copy_lib` / `logo_on_plate`；只调框与动画 |
| M-04 | 口播精简句 ↔ 本镜新增内容；贴纸只抓 **关键词/钩子** |
| M-05 | **排版简洁渐进**（见 §2）：先空舞台 → 再主块 → 再关键词贴 |
| M-06 | **基于事实**（见 §2.5）：名词/Logo/全称可溯源到 research 或官方 |
| M-07 | **字幕安全区**（见 §2.1）：底边留给后期字幕；贴纸与主内容上移到安全内容区 |
| M-08 | **短语完整**（见 §2.0.1）：片名、完整专名、自然短句 **一贴说完**；只拆彼此独立的关键词 |

## 2. 排版简洁 + 渐进揭示（生图与成片都要遵守）

生成这种风格的图、贴纸、以及 Remotion 贴层时，**布局与文字都要简洁、可渐进**，不是一次性堆满。

### 2.0 渐进节奏（时间 × 版面）

```text
T0    底图（干净，最多 1 个常驻角色/氛围）
T1    + 1 个主内容块（本镜核心）
T2    + 1～2 个关键词贴纸（服务该核心）
T3    （可选）短钩子贴纸 / 问句
禁止   T0 就把终局信息画满
```

| 规则 | 要求 |
|------|------|
| **一镜一主信息** | 观众暂停中段应只「多懂了一点」 |
| **关键词有限** | 单镜屏上新出现专业词贴纸 **≤3 个**（路线图类专镜可放宽，但须 enter_order 逐个点） |
| **留白** | 主内容区周围保留呼吸；禁止四角塞满贴 |
| **字幕安全区** | **底边只留给后期字幕**，不是贴纸区（见 §2.1）；禁止关键信息贴底 |
| **字阶** | 标题贴纸 > 关键词贴 > 辅助贴；同屏不超过 **3 级** 字号 |
| **对齐** | 多块内容用隐含网格（水平一排 / 弧线），忌随机乱飞除非「砸入」有意设计 |
| **生图单层** | 每张 gen 图：单主体 + 大留白；**不要**在图里排完整段说明 |

### 2.1 字幕安全区（强制 · 防后期字幕遮挡）

> 成片**会加字幕**（剪映/烧录/平台硬字幕）。贴纸字与内容块若贴太底，会被字幕挡住。  
> **底边 = 字幕带，不是贴纸带。**

#### 画幅分区（1920×1080 默认）

```text
┌────────────────────────────────────────────┐
│  顶安全 ~80–100px（可轻放角标，勿堆主信息）   │
│                                            │
│           ★ 安全内容区 ★                    │
│     贴纸 / Logo / 路线图 / 主内容块          │
│     优先：垂直中带 ~y 280–720（中心偏上）     │
│                                            │
│  ─ ─ ─ 内容底线 y ≈ 1080 − subtitle_band ─ ─ │
│     字幕带 subtitle_band（默认 160–200px）    │
│     仅字幕；禁止关键贴纸/节点/关键词           │
└────────────────────────────────────────────┘
```

| 参数 | 默认（1080p） | 说明 |
|------|----------------|------|
| `subtitle_band` | **160–200px** | 自画幅底边向上；双行字幕/大号字用 **200px** |
| 内容底线 | `y ≤ height − subtitle_band` | 任意关键层的 **包围盒底边** 不得超过此线 |
| 推荐主信息垂直 | 约 **中上 1/3～中带** | 横排路线图/胶囊条也要抬高，勿贴底一排 |
| 左右安全 | ≥ 80–100px | 与平台裁切；次要 |

#### 禁止（C-11）

| 禁止 | 原因 |
|------|------|
| 九站胶囊 / 热词 burst **整排贴底** | 字幕一盖，站名全没 |
| 落点长句贴纸贴在底边 | 与字幕叠字 |
| 「底边留给贴纸」的旧理解 | **错误**：底边只给字幕 |
| 用放大/下移把主视觉顶进字幕带 | 后期无法救 |

#### 必须

| 必须 | 做法 |
|------|------|
| 横排节点（如 1 LLM … 9 Skills） | 放在 **垂直中带或中上**；与底边至少空出 `subtitle_band` |
| 贴纸字 | 跟内容块走，落在安全内容区；问句 cloud 可偏上 |
| Remotion | `theme.safe.bottom` / `subtitleBand` ≥ 160；布局常量写死，勿魔法数贴 0 |
| 生图 | prompt 写明：subject in upper/middle frame，bottom 15–20% empty for captions |
| 验收 | still 时想象一条底字幕；关键字仍完整可读 |

#### 与「少贴片 / 别太贴边」

- **不要贴太满**：同屏贴纸少、渐进；也 **不要贴太底**  
- 空间不够时：**减贴纸或上移**，禁止为塞内容侵入字幕带  

### 2.0.1 贴纸字排版

| 规则 | 要求 |
|------|------|
| 长度 | 中文主贴 **≤16 字**；英文专名保持官方拼写（Token / Prompt / Agent…） |
| 数量 | 同时新出现的贴纸字 **≤3**；更多则拆 enter_order |
| 内容 | 只放 **关键词、短钩子、站名**；定义句交给口播 |
| 形态 | tape / cloud / burst / banner / round；**禁止**无边框灰底系统字条当主文案 |
| 与口播 | 贴纸 ⊆ 本镜口播要点；不出现口播没提、事实稿没有的词 |
| **短语完整** | 见下表；**禁止**为叠层动效把一句完整话硬切成两截 |

#### 短语完整（C-12 / M-08 · 强制）

> 观众读的是**意思**，不是「两张色块」。一整句/一个片名拆成两贴，看起来像排版事故。

| 该 **一贴**（完整） | 不要拆成 |
|---------------------|----------|
| `AI 时代基础知识` | `AI 时代` + `基础知识` |
| `Large Language Model` | `Large` + `Language Model`（除非在讲拆词教学且口播明确） |
| `通识 · 事实优先` | `通识` + `事实优先`（副标本身是一条） |
| `会猜下一个词的巨型语言引擎` | 为美观切半句（超 16 字则**改短**，不是拦腰拆） |

| 可以多贴（彼此独立） | 说明 |
|----------------------|------|
| `Token` / `Prompt` / `Agent` | 多个**独立关键词**依次砸入 |
| `LLM` 与 `第 1 站` | 站号 + 站名可两贴，但是**两个标签**不是同一句话切开 |
| 片名 + 副标 | `AI 时代基础知识`（主）与 `通识 · 事实优先`（副）——**两条完整信息**，不是一句切两半 |

判定口诀：

```text
念出来是不是同一口气的一句话/一个专名？
  → 是：必须同一 StickerText（可 PopIn 一次）
  → 否：才允许多贴 + enter_order
超长：优先缩短文案或换 shape=banner 单行，禁止「上下两截硬拆」
```

### 2.0.2 AI 生图时的排版约束（写进 prompt）

生图 / 改图必须带类似约束（可压缩进 design-lock（0060））：

```text
- 单主体或单贴纸；大量留白；不要大段说明文字
- 若需字：最多 1 个短词/短标签，官方拼写；其余字留给工程贴纸层
- 构图为后期叠加留空（一侧或中心净空）
- 主体放在画面中上/中带；底部 15%～20% 留空给字幕，禁止贴底排字/排节点
- 禁止把终局多零件、多词全部画进一张图
```

## 2A. 基于事实（专业名词 · 品牌 · 文案）

**漫画是表达，不是编造。** 屏上出现的专名与品牌必须可核对。

### 2.5.1 事实源优先级

1. 本集 `media/research`（或 `制作/research`）/ 0040 事实稿  
2. 0050 元素稿与口播定稿中的用词  
3. 官方文档 / 官方 brand assets（Logo）  
4. **禁止** 模型「感觉像」就发明产品名、乱写全称、乱造数据  

### 2.5.2 专业名词

| 规则 | 说明 |
|------|------|
| 用词统一 | 全片同一概念同一写法（如「上下文」与 Context 对应关系写死在元素稿） |
| 英文专名 | 保持通识约定拼写：Token、Prompt、Agent、MCP、LLM、Skills… |
| 中文 | 与口播一致；不另造「更炫」的黑话 |
| 全称 | 若出全称须事实正确（如 MCP = Model Context Protocol，以 research 为准） |
| 不确定 | 贴纸先不写；标「待核」回 0040，禁止猜 |

### 2.5.3 品牌 Logo 与名称

| 规则 | 说明 |
|------|------|
| 名称 | 官方产品名：ChatGPT、Claude、Kimi、DeepSeek… |
| 文件 | `shared/icons` 或 `logo-*.png` **原样** |
| 风格微调 | **仅** 外框/卡片/阴影/入场；**不改** Logo 矢量/像素本体 |
| 禁止 | AI 画「像某某」的替代标、换色标、假吉祥物当真标 |
| 清单 | 每条 logo 写 `source:` 真实路径 |

### 2.5.4 事实 × 贴纸自检

- [ ] 每个屏上关键词能在口播或 research 找到出处  
- [ ] 每个品牌名与 Logo 文件对应正确  
- [ ] 无「为了好看」多出来的术语贴

## 3. 视觉语法（定死这套）

### 3.1 底

| Token | 建议 |
|-------|------|
| 纸色 | 暖灰白 / 米纸 `#F3EFE6`～`#F7F4EE` |
| 线 | 深墨描边 `#1A1F2E`～`#2B3348`，**粗且匀** |
| 高光色 | 冰蓝/雾橙 **小面积** |
| 阴影 | 硬漫画偏移阴影优先于大模糊 |

### 3.2 内容块

- 形态：圆角卡、邮票框、画框、圆徽章  
- 入场：`PopIn`（scale + 上移 + 轻旋转）  
- 间隔：同镜多块约 12～18 帧 @30fps  
- **一镜主增量**优先  

### 3.3 贴纸字形状

| 形状 | 用途 |
|------|------|
| `tape` | 章标签、短提示 |
| `cloud` | 问句 |
| `burst` | 热词强调 |
| `banner` | 标题、站名 |
| `round` | 进度、小标签 |

（长度/数量/事实见 §2.0.1、§2.5）

### 3.4 真 Logo

```text
✅  shared/icons 或 public/logo-*.png 原样 + logo_plate
✅  仅框/阴影/入场漫画化
❌  AI 重画标、改色、假吉祥物
❌  type=logo + method=ai_gen
```

## 4. 工程约定（ComicKit）

参考实现（本仓样例）：

```text
remotion-friendly/src/components/ComicKit.tsx
  ComicBase / ComicChapter   → ① 底图
  ContentChunk / PopIn       → ② 内容块
  StickerText                → ③ 贴纸字
```

### 组件选用

| 需求 | 用 |
|------|-----|
| 章舞台 | `ComicChapter bgFile={...}` |
| 可换底 | `public/comic/bg-{chapter}.jpg`；无文件则程序纸纹底 |
| 往上加一块 | `ContentChunk` + `enter` |
| 屏上字 | **只用** `StickerText`，不用裸 `<div>标题</div>` |
| 品牌 | `Img staticFile(logo-*.png)` 放进 ContentChunk |

### Remotion 时序

```text
frame 0:     底图在
frame enter: 内容块 PopIn
frame enter+δ: 相关贴纸字 PopIn
禁止: 一张 full_composite 从 0 显示到结束当「动画」
```

### 布局常量（与 §2.1 对齐）

```text
subtitleBandPx ≥ 160   // 推荐 180–200（双行字幕）
contentMaxBottom = height - subtitleBandPx
// 贴纸 / 路线图 / Logo 行：bottom 或 centerY 须保证包围盒底 < contentMaxBottom
// 禁止 style={{ bottom: 20 }} 一类贴底关键信息
```

## 7. 验收清单

**分层**

- [ ] 底 / 内容 / 贴纸字可分开指认  
- [ ] 镜中段暂停时信息未终局堆满  

**简洁渐进**

- [ ] 本镜新关键词贴 ≤3（或路线图类已逐个 enter）  
- [ ] 贴纸中文 ≤16 字；无挤版  
- [ ] 生图层未烤长说明文  

**短语完整（§2.0.1）**

- [ ] 片名/完整专名/自然短句未硬拆成两截色块  
- [ ] 多贴仅用于彼此独立的关键词或「主+副」两条信息  

**字幕安全区（§2.1）**

- [ ] 底边 `subtitle_band`（≥160px）内无关键贴纸/节点/关键词  
- [ ] 横排路线图/胶囊条已抬到中带，非贴底  
- [ ] still 想象底字幕后关键字仍完整  

**基于事实**

- [ ] 专名与口播/research 一致  
- [ ] 品牌名正确；Logo 为真实文件可辨认
