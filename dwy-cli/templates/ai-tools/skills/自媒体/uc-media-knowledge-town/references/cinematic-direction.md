# 电影化导演规则

## Cue 模板

每个 cue 先写五行，再画画面：

```text
事实来源：0030 facts / 已批准口播的句子
主问题：观众此刻要解决的一个问题
主动作：角色或英雄道具完成的一个动作
可见结果：动作结束后唯一留下的新理解
术语揭示：只在结果出现一次；没有必要则留空
```

禁止把“方便讲解的道具名”写成技术结论。比如 token 只能表现为“模型处理的文字小块，切分因模型而异”，不能用一个汉字断言一个 token。

## 镜头语法

1. **建立**：一名角色或一个道具进入可感知空间。
2. **推进**：镜头推近唯一关键物；让它递交、拆开、选择、比较、盖章或折叠。
3. **结果**：旧元素退场，只留一个新结果物；术语在这一拍出现。
4. **转场**：结果物变成下一场的入口；不硬切到说明板。

## 动效硬门槛

每个 cue 都必须列出并实现以下三项：

1. **叙事动作**：让信息发生变化，例如纸带送入、候选弹出、词卡回指、答案被选中、来源被扫查。
2. **低频质感微动**：幅度小、速度慢，服务空间与材质，例如纸张 2–4px 呼吸、光圈扩散、前中后景视差、阴影微偏移。
3. **明确落点**：动作结束后只留下一个可理解的结果，配一个准确 SFX 或 6–12 帧静默停顿。

禁止用循环摇晃、无目的漂浮或持续旋转凑动效；它们不计入覆盖。

## 场景图与叠放规范

每个 cue 在编码前先给元素编号，并写清“何时出现、何时消失、处于哪层”。没有退场规则的元素不得进入下一 cue；例外只允许一个明确的转场物。

```text
bg(0–9) → stage(10–19) → connector(20–29) → prop(30–39)
→ readable-card(40–49) → foreground-sticker(50–59) → caption(60+)
```

- 连线和箭头只在两个对象都可见时绘制，位于对象下层；箭头尖端停在目标外沿 `8–16px`，不穿入卡片、描边或阴影。
- 同一术语只能有一个屏幕承载点；优先顶部关键词，其余区域只呈现动作或事实例子。
- 对象做汇聚动画时，必须指定不同的最终落点；禁止多个标签落在同一坐标。
- 圆圈、光晕、箭头、连线和图标都要有明确的叙事对象与解释：高亮贴合目标形状；箭头从原因对象出发、停在结果对象外沿。不能说明“它在指谁、为何此刻出现”的装饰，一律删除。
- 关系箭头统一为深蓝描边、珊瑚红纸带、固定小箭头头部与绘制入场，并以对象之间的水平直连为默认。禁止弧线、绕行线、默认字符箭头、CSS 三角箭头和无描边线条混用。
- 每段运动抽检 `25% / 50% / 75% / 90%` 帧，按含阴影的真实包围盒查碰撞。发现遮挡、叠字、残留线条时，先修生命周期/层级，再调坐标。

## 常用配方

| 讲解意图 | 电影动作 | 结果物 |
| --- | --- | --- |
| 预测候选 | 空位被推近，候选依次弹出，选中一张 | 被接回句尾的纸片 |
| 上下文关系 | 指代词孤立，手电只连到相关词 | 一条定格关系线 |
| 历史 | 引擎变车头，列车一次只停一站 | 下一站入口 |
| 训练步骤 | 黑暗中一次只开一扇门 | 当前步骤的门牌 |
| 可靠性 | 答案纸滑出，印章落下，具体处剥落 | 放大镜下的来源标签 |
| 收束 | 已验证概念按口播顺序折成路径 | 一个可提问的结尾 |

## 验收

逐帧检查建立、推进、结果、转场四帧：

- 是否只看得出一个主问题和一个动作？
- 是否所有文字和因果能回溯至 facts/口播？
- 是否术语只出现一次，且没有被字幕或顶部关键词重复？
- 是否旧画面已清场，没有遮挡、交叉线或站桩角色？
- 是否结果物能自然带入下一 cue？
- 是否每个 cue 都有叙事动作、低频质感微动和明确落点？
- 文字卡、术语贴纸、角色名牌是否包含描边与阴影后仍互不相撞（最小 `24px`）？
- 所有箭头、连线、光束是否只在对象间空隙中运动，尖端离对象外沿 `8–16px`，没有覆盖文字或边框？
- 纸条角、气泡尾巴、折页边是否为完整闭合形状，没有孤立折线或半截图形？
