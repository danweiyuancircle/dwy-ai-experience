# 知识小城视觉规范

以 LLM 集 `S01PaperFilmPreview` 为频道贴纸系统的唯一母版。它统一素材语言，不限制每期的主题空间、道具或镜头。

## 频道贴纸系统（固定）

| 项目 | 标准 |
|---|---|
| 纸张 | 暖米纸底 `#f4e8c6`、可见米纸纹；卡片底 `#fffdf5` |
| 描边 | 深海军蓝 `#14213d` 粗描边 |
| 强调色 | 明黄 `#ffd161`、青绿 `#77dfd1`、珊瑚粉 `#ff9cb9`；只作小面积强调 |
| 阴影 | 深海军蓝硬边偏移阴影，默认 `10px 12px 0 #14213d`；不用纯黑或柔焦阴影 |
| 文字 | 文字由 Remotion 渲染；贴纸有粗描边、圆角与硬阴影，不烤进生图 |
| 字幕 | 底部对白框，最多两行；不与术语贴纸重复同一词 |

所有自制角色、道具、术语卡、事实卡、关系箭头、档案框和地图收束件都必须使用这套 Token。不要引入玻璃拟态、渐变贴纸、3D、写实主体或第二套卡片/箭头体系。

### 标准组件

- **角色名牌**：只在首次入场或身份需要识别时出现；明黄或青绿底、海军蓝描边与硬阴影。
- **术语贴纸**：在动作产生可见结果后出现一次，使用米白或强调色底；不得和字幕重复。
- **档案贴纸框**：真实截图、GitHub 页面、项目界面和资料图保持原貌，只放入统一海军蓝描边的框内。
- **关系箭头**：深海军蓝描边 + 珊瑚色纸带 + 绘制入场；只连接有因果关系的两个对象。
- **底部对白框**：所有主题共用，留出 `180px` 字幕带；不能被道具或角色侵入。

## 主题叙事世界（可变）

许可证闸机、聊天门、档案列车、实验室、地图等都只是主题实例。每期可以自由改变场景、道具、构图、景别、机位、镜头推进与转场动作，但不得改变频道贴纸系统。

一场仍按 `问题 → 行动 → 意外或选择 → 结果` 展开。角色或英雄道具推进因果；卡片、箭头和时间线只能短暂作为道具状态，不可变成常驻讲解板。

## 素材准入

- 角色和单道具使用透明 PNG；先检查 alpha 边缘，再登记共享资产库。
- 在深海军蓝 `#14213d` 和暖米纸 `#f4e8c6` 底色各预览一次；出现洋红、绿幕残边、缺口或暗部被抠空即拒绝。
- 生图只输出角色、场景或单道具：禁止烤入中文、品牌 Logo、UI、事实结论和字幕。
- 真实截图不得重绘成纸片画；使用档案贴纸框，并在本集素材表记录来源。

## 叙事与对轨

每个 cue 依次经历 `prepare → action → label → hold → clear/transition`。先让观众看到动作和结果，再出现术语贴纸。每个 cue 只保留一个主角/道具/信息对象组合；上一 cue 的元素必须退场或折成明确的转场物。

详细镜头、层级、文字和碰撞验收规则见 [`cinematic-direction.md`](./cinematic-direction.md)。0060 的生成提示词与透明素材验收见 [`sticker-asset-production.md`](./sticker-asset-production.md)。
