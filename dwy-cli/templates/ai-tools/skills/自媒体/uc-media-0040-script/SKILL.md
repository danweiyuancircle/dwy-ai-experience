# uc-media-0040-script · 脚本（蒸馏成片）

**模板：** [`templates/脚本.template.md`](./templates/脚本.template.md)

## 行为（本 skill 内聚）

1. **双上游蒸馏（必须同时读）**  
   - `0030-facts/事实-*.md` → **技术真相与可溯源细节**（作者深库；可含公式/长论证）  
   - `0010-product/产品卡-*.md` → **受众、讲/不讲、内容块与时长、语气**  
   - `0020-topic/选题-*.md`（若有）→ 标题/钩子/差异化讲法  
2. **能自动的全部自动**：按 0010 段级骨架，把 0030 里站得住的事实 **精简、翻译成人话**，一次写满脉络·分镜总表·逐镜口播。  
3. **蒸馏纪律**  
   - 口播深度对齐 **0010**，不是对齐 0030 全文深度。  
   - 0010「不讲」不得进观众口播；0030 深点可留在作者理解里，成片一句带过或砍掉。  
   - 0030 标〔待验证〕的内容 **不得**说成铁定。  
4. **不确定不胡编**：禁止编造机制/数据；缺事实回 0030 补库，不靠脑补写口播。  

**本步硬停：** 人审通过前不进 0050。
