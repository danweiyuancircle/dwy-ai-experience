# 单集科普骨架 · v1.1（标准主体结构）

> **用途：** 3–5 分钟、单概念、讲故事式自媒体短片的**默认骨架**。  
> **原则：** 主体结构统一；**各段可裁剪/降级**，非每段都必须满配。  
> **复用：** 新集复制同目录 [`单集文档.template.md`](./单集文档.template.md)，按本文件填段。  
> **所属 skill：** `uc-media-0040-script` · 标准目录 `templates/`

---

## 1. 一句话

```text
钩子（场景+缺口）→ 历史（何以至此）→ 事实（1 个机制）
  → 生活（1 主例）→ 边界（需要时）→ 验证（动手|演示|真图）→ 落点+下集
```

画面原则（贯穿，不是单独一大段）：**真截图 / 真 UI 优先**；插画只解释结构。

---

## 2. 七段定义

| 代号 | 段名 | 目标（观众得到什么） | 默认时长 | 必选？ |
|------|------|----------------------|----------|--------|
| **H** | 钩子 | 场景 + 认知缺口：为什么要看完 | 25–35s | **必选** |
| **T** | 历史 | ≤4 锚点，只服务「何以至此」 | 40–50s | 默认有；可 **缩/并** |
| **F** | 事实 | **1 个**机制模型，人话 | 60–75s | **必选** |
| **L** | 生活 | 1 主例 + 可选 1 辅 | 40–50s | **必选**（至少 1 主例） |
| **B** | 边界 | 幻觉 / 误用 / 能力边界 | 20–30s | **按需** |
| **V** | 验证 | 动手 \| 演示 \| 真图对照 | 30–40s | **按需**（三选一或组合） |
| **C** | 落点 | 记住一句 + 下集钩子 | 15–25s | **必选** |

合计默认约 **3:30–5:00**。压到 3′ 时优先砍 **T 与 V 时长**，不砍 H/F/L/C 的存在。

---

## 3. 必选 / 可裁剪规则

### 3.1 硬必选（缺了不像完整单集）

| 段 | 最低交付 |
|----|----------|
| **H** | 1 个观众已有场景 + 1 句缺口问题 |
| **F** | 1 个机制模型（可配「名字拆开」） |
| **L** | 1 个生活主例（辅例可删） |
| **C** | 1 句落点；系列片加下集钩子 |

### 3.2 默认可裁剪

| 段 | 何时保留 | 何时缩/删 | 降级写法 |
|----|----------|-----------|----------|
| **T 历史** | 名词有明确「进日常」节点 | 无公开史、或纯工具操作集 | 缩成 **1 句**「从…变成你桌上的…」并进 H 或 F |
| **B 边界** | 易神化/易误用（LLM、Agent、幻觉相关） | 纯中性术语且误用成本低 | 并入 F 末尾 1 句警告 |
| **V 验证** | 观众 30s 内能复现或看懂 | 训练全流程等无法跟做 | 改为 **演示录屏** 或 **1 张真图对照** |

### 3.3 验证段三选一（V）

| 模式 | 适用 | 例子 |
|------|------|------|
| **动手** | 对话框/设置里能点 | 半句续写、改一句 Prompt |
| **演示** | 环境重、需账号/装环境 | MCP 接工具、本地跑命令 |
| **真图对照** | 重在「认界面」 | Token 用量页、上下文截断提示 |

可组合：动手 20s + 真图 10s。

---

## 4. 时长配比（默认 4′ 片）

| 段 | 占比 | 约秒 | 硬顶 |
|----|------|------|------|
| H | 10–15% | 25–35 | — |
| T | 15–20% | 40–50 | **≤50s**；锚点 **≤4** |
| F | 25–30% | 60–75 | 机制只保留 **1 个主模型** |
| L | 15–20% | 40–50 | 主例 1；辅例 ≤1 |
| B | 8–12% | 20–30 | 可 0 |
| V | 10–15% | 30–40 | 可 0 或改演示 |
| C | 5–8% | 15–25 | 落点句必须有 |

**超时优先砍：** T 参数堆砌 → L 第二例子 → V 步骤数 → F 的次要比喻。

---

## 5. 各段写法清单（复用检查）

### H · 钩子

- [ ] 场景是观众**已经在做的事**（打开对话框、贴长文、看用量…）  
- [ ] 有**认知缺口**（不是「今天讲 XXX」）  
- [ ] 3 秒内出现本集名词或问题句  

### T · 历史

- [ ] 每个锚点都服务「何以进到你生活」  
- [ ] ≤4 点；不报排行榜/参数竞赛（除非本集主题就是规模）  
- [ ] 日期/机构可溯源（写进事实底稿）  

### F · 事实

- [ ] 只有 **1 条主机制**（如「猜下一个 token」）  
- [ ] 人话优先；公式/实现细节默认不进  
- [ ] 与 L 的例子不重复讲同一套比喻两遍  

### L · 生活

- [ ] 主例高共鸣、可一秒懂映射  
- [ ] 辅例可删；不新开第三条机制  

### B · 边界

- [ ] 具体误用场景，不空洞「要理性」  
- [ ] 与落点句一致（防神话）  

### V · 验证

- [ ] 步骤 ≤3；可静帧给观众照做  
- [ ] 真 UI，不 AI 假界面冒充  

### C · 落点

- [ ] **一句**可被记住（片尾花字）  
- [ ] 单集闭环：没看过上集也听得懂  
- [ ] 系列：下集钩子 1 句，不剧透成长文

## 6. 内容适配速查（本系列九站）

| 主题 | T | B | V 建议 |
|------|---|---|--------|
| LLM | 满配 3–4 锚点 | **要**（幻觉） | 动手：续写+冷门题 |
| 训练 | 可短 | 要（不是一次聊天就「学会」） | 演示/类比图，难动手 |
| Token | 可短 | 可选 | 真图：用量/计数界面 |
| Prompt | 可短 | 可选 | 动手：同一题两种写法 |
| 上下文 | 可短 | 要（会忘/装不下） | 真图：超长贴入被截 |
| 多模态 | 中 | 要（乱认图） | 演示：图+文同问 |
| Agent | 中 | **要**（乱调工具） | 演示：想做看循环 |
| MCP | 要（谁发布） | 可选 | 演示：接一个 server |
| Skills | 要（和 prompt 区别） | 可选 | 真图：技能包/说明页 |

## 7. 目录与流水线（和 media 契约对齐）

```text
0N-主题/
  research/事实-*.md           # 0040 向：只锁可讲事实
  scripts/单集文档-*.md        # 按 单集文档.template 填满 v1.1
  assets/_real-shots/          # 真截图
  package/                     # 可选：短片 shots.json + 人审包
```

开发顺序建议（由 **uc-media-0040-script** 短集模式执行）：

```text
1. 填产品卡 + 选定段（哪些满配/缩/删）
2. 事实底稿（口播只讲有源内容；字段见 事实.template.md）
3. 按 H→…→C 写口播（对时长表）
4. 分镜 + 真图清单
5. 人审 → 配音/package/成片
```

模板路径：本 skill 包内 `templates/`（sync 后：`.claude/skills/uc-media-0040-script/templates/` 或 `.agents/skills/…`）
