# iOS 弹窗差异与案例

- 共通锚点规则和验证见 `dwy-swift-development` 的弹层参考。
- iPhone 的 popover 默认适配为 sheet，垂直紧凑环境可适配为全屏；iOS 常规尺寸类别的 confirmation dialog 可以呈现为 popover。按设备和尺寸类别验证，勿假设始终有箭头。
- 对指定 `arrowEdge` 的 SwiftUI popover，iOS 18.1 前系统不遵循指定边；新行为还要求使用 iOS 18.1 或更新 SDK 编译并运行在对应系统。允许系统选方向时使用不指定边的重载；按支持版本验证。
