# Mac 设计规范与组件复用

- 先核对项目采用的设计规范、基础库产品及锁定版本。已采用的组件优先复用；本 Skill 不要求所有项目安装同一组件库。抽取时按架构 Skill 区分通用控件、可复用业务与应用窗口状态。
- 规范应明确默认主题、语义 token、主次/危险/忙碌状态、键鼠路径、焦点/窗口归属和可访问性；具体配色与尺寸由项目/基础库文档维护，不硬编码进通用 Skill。
- Mac UI 独立于 iOS UI 产品。共用语义不等于共用手机布局；优先原生 controlSize、toolbar、Menu、Picker、NSWindow/NSPanel 行为。系统已有玻璃背景的区域避免重复叠加材质。
- 控件保留原生 ButtonRole、Binding、键盘与可访问名称。尺寸明确区分字形和命中；忙碌时保留名称，危险语义不被品牌 tint 覆盖，focus 与 selected 可共存。
- 公共文案保留原生可本地化类型或 Text/Label builder，库资源使用所属 target 的 bundle。主题使用稳定值配置；Environment、本地化与更新策略按可用的 Apple SwiftUI Skill 查证，不把闭包或高频业务更新塞入全局主题。
- 自绘建议框、popover 和确认呈现需验证滚动裁剪、窗口移动/缩放、屏幕边缘、首次点击、焦点恢复与取消；平台窗/应用生命周期留明确宿主，不由通用控件查找全局首个窗口。
- 独立示例只验证公开产品的可用性；最低系统、产物最低版本/架构和实际应用窗口仍分别验收。设计候选与原型不标为稳定组件；不因共享控件升级修改用户数据、全局隐私设置或产品业务权限。
