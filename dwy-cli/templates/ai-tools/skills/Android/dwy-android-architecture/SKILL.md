# Android 架构

先检查项目实际结构、依赖方向、调用方和页面模式，不因启用本技能重建已有工程。需要模块边界时读 [分层与依赖](references/dwy-android-layering.md)，项目采用 MVP 或用户明确要求时读 [MVP](references/dwy-android-mvp.md)。新项目按照团队约定和实际规模决定，现有架构及用户要求优先。

历史资料中的 `dwy-android-core` 指 `dwy-android-development`；`dwy-android-layering` 和 `dwy-android-mvp` 指本 Skill 的对应资料。
