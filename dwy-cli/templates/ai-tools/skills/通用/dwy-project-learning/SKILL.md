# 项目经验

以当前任务的项目根目录为边界，经验保存在该项目的 `.dwy/dwy-project-learning/lessons.md`；即使 Skill 全局安装，也不写入用户主目录或 Skill 安装目录。项目根不明确时先确定，不能默认写入用户主目录。只查询时不创建文件。

开发或排查前按任务关键词查找相关经验，结合当前代码核实是否仍适用；不要把全部经验加载为通用规则。经验与用户指令或当前事实冲突时，以后者为准。

同一类问题出现至少两次时，只记录可跨任务复用的教训，写清现象、根因和避免方式；先查重，同类内容补充原条目。一次性问题不记录。写入后回读并在答复中告知路径；不要记录凭据、个人信息或不必要的敏感数据。经验是项目资料，遵守项目版本管理规则，不要把整个 `.dwy/` 加入忽略列表。

迁移旧记录时，检查项目根 `AGENTS.md` 中托管块之外的「[自成长] 项目规则」和 `.claude/rules/project-rules.md`；先合并去重并回读确认完整，再移除已迁移内容。保留其他内容和托管块，不自动处理其他项目或用户全局文件。无法安全确认归属或迁移结果时保留原文并说明。
