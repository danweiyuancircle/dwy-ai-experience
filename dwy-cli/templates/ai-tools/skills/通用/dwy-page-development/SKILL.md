# 页面开发：信息克制与清晰交互

页面围绕用户当前任务组织：必要内容、可用操作、真实状态。辅助文字只有在影响当前操作或判断时才进入主界面。留白不需要靠文字填满。

本 Skill 将 impeccable 的 distill（删减冗余、渐进披露）和 clarify（消息层级、可操作文案）前置到开发过程，核心约束自包含，不依赖安装 impeccable。配色、字体、组件和平台交互继续遵循项目设计规范，不借简化重设计页面或删减已约定功能。

## 开发前：确定信息去向

先读相关页面、调用链与产品要求，确认用户当前任务、已有入口和实际状态。局部修改只检查本次影响范围，不扩大成整站审计。

将本次新增或调整的信息分配到以下位置；在工作分析中完成，不把这份分类写进产品页面：

| 位置 | 内容 |
|---|---|
| 主界面常驻 | 用户内容、明确标签、当前任务所需操作、会影响选择的真实状态 |
| 相关控件旁 | 输入格式和限制、权限用途、会改变操作结果的条件 |
| 对应状态中 | 正在处理、无结果、失败原因、恢复操作、必要的成功反馈 |
| 帮助或按需展开 | 低频操作方法、快捷键说明、详细机制；使用已有入口，确有必要才新增 |
| 开发记录或日志 | 实现细节、执行过程、调试信息、向开发者解释的设计理由 |

用户明确要求教程、引导或说明型内容时，按该内容的实际阅读任务设计，不机械套用操作页面的删减标准。

## 实现时：先决定要不要，再决定怎么写

### 辅助文案准入

对每条新增辅助文字，明确：**哪个用户，在什么状态下，缺少这句话会做错或无法完成哪一步？**

- 能从真实需求、已观察到的使用障碍或调用链回答：放到上表中最贴近该操作的位置。
- 只能回答“可能不知道”“显得专业”“让页面丰富”：不新增。
- 涉及业务行为但无法确认：先查实现；仍无法确认则指出缺口，不编造承诺。

常驻说明不得复述控件名称、标题或已有状态。同一状态、同一任务中的信息只表达一次；不同步骤各自必要的输入限制和风险提示可以在当地展示。

### 信息与交互

- 标签直接表达动作和对象，如“导出用户”；不另加“点击按钮即可导出用户”。
- 优先用清楚的名称、控件状态和合理布局表达交互。页面底部不堆“点击后会怎样”的常驻说明。
- 非显然且影响结果的行为，在操作前就近说明；低频技巧放帮助。必要信息不能只藏在 hover 提示中，触屏和键盘用户也必须可访问。
- 当前没有数据时，展示该状态和可用的下一步；不为填版面增加介绍、提示卡、统计卡或重复按钮。
- 设置项的名称已足以判断用途时，不强配副标题。名称不能表达的重要副作用或生效条件，就近补充，并以真实实现为准。

### 状态与错误

- 按真实状态分别呈现首次使用、未连接、无搜索结果、无权限和读取失败；不能统一写“暂无数据”。
- 故障发生时，说明失败对象、已知且有用的原因、可行的下一步；原因未知就不猜。失败提示留到问题解决或用户主动关闭，不以短暂 toast 代替阻塞错误。
- 输入限制在提交前可见；错误贴近相关输入。删除后果、支付条件、权限与隐私用途、不可逆风险必须在作出决定前可见。
- 执行日志不直接充当用户状态。“已读取设备状态”不值得常驻；实际未授权时，才显示对应的授权操作。
- 成功反馈与操作重要性匹配，不叠加 toast、横幅和底部状态重复报告同一结果。

### 简化的边界

只删除本次范围内的重复表达和无任务价值的装饰，不删除必要功能、校验、持久标签、无障碍名称或错误处理。不通过小字号、低对比度、截断或仅用图标隐藏必要文字。遵循平台字号与对比度要求，不设所有页面通用的字数、字号或提示数量上限。

## 交付前：删减检查，再做清晰度检查

1. **distill 检查**：逐条审查本次辅助文字和提示容器；不能通过准入问题的删除，重复的合并，低频的移到合适入口。移走后保留必要信息的可达性，不增加一套无人需要的帮助系统。
2. **clarify 检查**：从用户入口走到结果，检查术语、动作、状态、后果和恢复路径；保留完整意义，不只追求短。
3. **实际验证**：在可运行的页面上检查本次影响的正常及异常状态、目标窗口宽度、文本放大或系统动态字体、键盘与触屏可达性。按平台和改动选择验证项，不要求无关平台全跑。
4. **报告结果**：在交付回复中简述删减或保留的重要信息及实际验证范围；不把验收说明加到产品页面。无法运行或无法构造的状态明确标注未验证，静态检查不等于视觉验收。

## 示例：设备管理页

未连接设备时，主区域显示“尚未连接手机”和已有的连接入口；应用区无需再重复整套连接提示。连接帮助保留版本、网络与授权要求。

“点击应用打开独立窗口，再次点击会聚焦原窗口；关闭只结束该窗口的画面”不作为常驻页脚：普通打开行为交给明确的入口表达，低频窗口规则放已有帮助。如果关闭会中断用户正在执行的任务，则按真实后果在关闭前就近说明。“已读取设备状态”留在日志；确实未授权时，在设备状态旁显示“请在手机上允许 USB 调试”。

反例边界：上传页的“PNG/JPG，最大 10 MB”和永久删除确认中的“删除后无法恢复”会改变用户选择，必须保留；不能因它们也是小字就删除。
