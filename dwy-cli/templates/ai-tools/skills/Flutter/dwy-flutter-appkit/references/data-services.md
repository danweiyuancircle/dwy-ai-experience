# 数据与基础服务

先按 `version-resolution.md` 确认实际源码，再查各包 `flutter/packages/<包名>/README.md`、公开入口和测试。以下是接入检查点，不保证任意历史版本具有相同接口。

| 包 | 接入时确认 |
| --- | --- |
| `dwy_network` | 按服务注入和关闭客户端；响应解码、认证及会话策略由产品配置。核对取消作用域、真实进度、上传文件授权，以及下载返回文件的所有权和清理方式，不把日志失败变成请求重试 |
| `dwy_log` | await 异步操作并处理落盘错误；日志内容最小化，脱敏不代表可以记录秘密。核对 flush、导出、关闭及故障状态；导出快照由宿主负责后续分享与清理 |
| `dwy_preferences` | 首次调用前完成 binding 初始化；使用产品/账户作用域。偏好不存凭据、订单或重要业务记录；账号清理前停写，不把非事务清理当作原子操作 |
| `dwy_secure_storage` | 按账户建立作用域，只清自己的键；不承诺卸载即撤销凭据。核对 Keychain/Keystore、备份和恢复配置；部分删除失败必须向业务报告 |
| `dwy_database` | 产品拥有路径、schema、DAO 和迁移；使用持久目录。核对 isolate 和 owner 生命周期，停写并结束事务/订阅后再关闭；迁移失败不能删库冒充恢复 |

数据库代码生成与迁移示例按对应源码的 `flutter/packages/edatabase/example/` 查找，不把示例业务表移入共享库。分析、单测、磁盘持久化和移动端插件验收分别记录，内存替身不能证明设备存储行为。
