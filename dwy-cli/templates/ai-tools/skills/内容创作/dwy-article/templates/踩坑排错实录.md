# 踩坑排错实录模板

定位：还原一次真实的破案过程。**把弯路也写上**，读者跟着你一起查才有代入感、才学得到。

固定锚点，按顺序：

```
# 标题：什么现象 + 一句话定性（如「线上接口偶发 502，查了两天是它」）

[现象] 1-2 段：什么场景下出的问题，表现是什么，多严重。给真实的报错 / 日志。

## 排查过程
按你**真实的排查顺序**走：怀疑过什么 → 怎么验证 → 排除了什么。把走过的弯路、错误的猜测也写上，这才真实有用。

## 根因
最后定位到的真正原因，讲清楚为什么会这样。

## 解决
怎么修的，给完整的改动 / 命令。顺带说一句怎么防复发。

[落点] 这事的泛化教训——同类问题以后怎么更快定位。不升华。
```

含命令 / 日志 / 报错的地方要完整真实，工整不算 AI 味。
