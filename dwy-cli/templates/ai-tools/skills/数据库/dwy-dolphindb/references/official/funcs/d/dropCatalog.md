# dropCatalog

## 语法

`dropCatalog(catalog)`

## 详情

删除指定的 catalog。

## 参数

**catalog** 字符串标量，表示 catalog 的名称。

## 返回值

无。

## 例子

```dolphindb
dropCatalog("catalog1")
```
