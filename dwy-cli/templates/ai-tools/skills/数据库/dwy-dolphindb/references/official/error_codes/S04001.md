# S04001

## 错误代码

S04001

## 报错信息

- The database [" + s + "] does not exist. RefId: S04001
- The table [" + s + "] does not exist. RefId: S04001

## 错误原因

当对不存在的库或者表设置权限 grant 时，则会报上述错误。

## 解决办法

先创建对应的库和表，再设置权限。
