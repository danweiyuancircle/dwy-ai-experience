# S03039

## 错误代码

S03039

## 报错信息

Failed to serialize events due to incompatible event fields. Expected: <xxx>.
Actual: <xxx>. RefId: S03039

## 错误原因

传入的事件的字段数量和 streamEventSerializer 定义的 eventSchema 中指定的 eventField 数量不一致。

## 解决办法

检查传入的 event 类型和 StreamEventSerializer 定义的 eventSchema 是否一致。
