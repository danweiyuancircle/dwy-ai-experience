# S02014

## 错误代码

S02014

## 报错信息

The right part of a join must be a table. RefId:S02014

## 错误原因

表连接函数（例如 `ej`, `lj` 等）的第二个参数 *rightTable*的类型必须是表。当 *rightTable*指定为非表时，将触发错误。例子：

```dolphindb
login(`admin, `123456)
id = `XOM`GS`AAPL
x = 102.1 33.4 73.6
t = table(id, x);

select * from ej(t, id, `id)
```

## 解决办法

检查脚本中是否存在表连接函数，其第二个参数 *rightTable* 的类型不是表。
