# createCatalog

## 语法

`createCatalog(catalog)`

## 详情

创建一个 catalog。

## 参数

**catalog** 字符串标量，表示 catalog 的名称。

## 返回值

无。

## 例子

```dolphindb
createCatalog("catalog1")
```
