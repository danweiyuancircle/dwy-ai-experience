# 链式比较

## 语法

允许在单个表达式中串联多个比较运算符（<, <=, >, >=, ==, !=, <>）。例如，`X < Y <=
Z` 等价于 `X < Y && Y <= Z`。

## 参数

参数可以是标量、数据对、向量、矩阵或集合。当 **X**, **Y**, **Z** 都是向量或矩阵时，它们的长度或维度必须相同。

## 例子

```dolphindb
1<2<=3.5;
//等价于 1<2&&2<=3.5
// output: 1

NULL<1<3>=2<3!=1>=NULL;
//等价于 NULL<1&&1<3&&3>=2&&2<3&&3!=1&&1>=NULL
// output: 1

1<3>1==2<3!=1;
//等价于 1<3&&3>1&&1==2&&2<3&&3!=1
// output: 0

1 2 3 >=2 ==1 2 3;
//等价于 1 2 3 >=2&&2==1 2 3
// output: [0,1,0]

1 2 3 <= 3 2 2 > 2 1 2;
//等价于 1 2 3 <= 3 2 2&&3 2 2 > 2 1 2
// output: [1,1,0]
```
