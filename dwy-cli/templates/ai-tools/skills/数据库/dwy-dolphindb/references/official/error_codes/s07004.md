# S07004

## 错误代码

S07004

## 报错信息

Data type x is not supported as index key. Supported data types include CHAR, BOOL,
SHORT, INT, LONG, STRING, and temporal types. RefId: S07004

## 错误原因

目前 OLTP 只支持以下数据类型作为索引的键：CHAR, BOOL, SHORT, INT, LONG, STRING 以及所有时间类型。

## 解决办法

选择符合类型要求的列作为索引的键。
