# iOS/macOS 截图工作流

## 采集

从真实 iOS 模拟器和 macOS 应用构建采集截图。先向用户确认截图剧本：启动方式、测试账号引用、页面路径、测试数据、脱敏规则和中英文文案。禁止以与实际应用不一致的生成图替代功能展示。

## 分平台输出

- iOS 和 macOS 必须分别采集、设计、校验和上传，不能将同一图片简单缩放复用。
- 每种平台、设备尺寸和语言输出 1 到 10 张 JPEG/JPG/PNG；不得包含 Alpha 通道。
- macOS 使用 16:10：`1280x800`、`1440x900`、`2560x1600` 或 `2880x1800`。
- iOS 根据目标 iPhone 展示尺寸选择 Apple 当前接受的规格；执行时先读取 Apple 官方截图规格，避免使用过期机型尺寸。

## 上传前检查

检查尺寸、方向、格式、无透明通道、语言目录、页面顺序、隐私脱敏和平台归属。先生成本地预览和上传清单，用户确认后才上传。
