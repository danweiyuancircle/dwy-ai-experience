# dwy-notify

多目标通知配置、字段与发送结果；核实目标配置、失败与实际发送行为。

## 查找与使用

项目使用 0.3.2 时可阅读 [0.3.2 接入和示例](references/v0/0.3.2.md)；其他版本先查该版本的资料和代码，不把此快照当作其他版本的合同。

1. 检查项目锁文件和当前 Python 环境；用 `importlib.metadata.version("dwy-notify")` 查询实际发行版本，依赖范围不等于实际安装版本。未安装时不得假设可用或自动安装。
2. 在实际环境中检查 `dwy_notify` 的公开接口、类型及项目已有调用；editable 安装以实际源码为准。说明、实现或安装版本不一致时以运行代码为准。
3. 本索引基于仓库 0.3.2，能力与签名可能随小版本变化。精确版本源码位于仓库 `backend/packages/notify`，文档为该目录的 `README.md`；只在确认其版本与消费项目一致时使用。缺少安装源码时查对应 `dwy-notify@版本` 标签，不能用默认分支冒充。
4. 在已有调用和该版本文档中核对配置、必需依赖、输入校验、失败处理及生命周期后接入。没有足够证据时说明缺口，不猜 API。

## 0.x 已核实差异

- 0.2.0 起发送者名称必须有明确来源；0.2.1 提供来源无关事件合同与可选持久队列。
- 0.3.0 增加与宿主事务共用的入队和指定失败目标重放；0.3.1 增加通知字段渲染；0.3.2 调整 dwyeapi 兼容范围。较早版本不要假设这些能力存在。

不要因为发现此库就改动项目依赖；新增依赖遵循项目选型规则。关联 FastAPI 或其他自有包时同时参考可用的对应 Skill。
