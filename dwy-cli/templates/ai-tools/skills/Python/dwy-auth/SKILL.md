# dwy-auth

认证主体、邮箱验证码、会话和管理端认证；核实适配器、配置、存储及 HTTP 路由由宿主如何装配。

## 查找与使用

项目使用 0.2.0 时可阅读 [0.2.0 接入和示例](references/v0/0.2.0.md)；其他版本先查该版本的资料和代码，不把此快照当作其他版本的合同。

1. 检查项目锁文件和当前 Python 环境；用 `importlib.metadata.version("dwy-auth")` 查询实际发行版本，依赖范围不等于实际安装版本。未安装时不得假设可用或自动安装。
2. 在实际环境中检查 `dwy_auth` 的公开接口、类型及项目已有调用；editable 安装以实际源码为准。说明、实现或安装版本不一致时以运行代码为准。
3. 本索引基于仓库 0.2.0，能力与签名可能随小版本变化。精确版本源码位于仓库 `backend/packages/auth`，文档为该目录的 `README.md`；只在确认其版本与消费项目一致时使用。缺少安装源码时查对应 `dwy-auth@版本` 标签，不能用默认分支冒充。
4. 在已有调用和该版本文档中核对配置、必需依赖、输入校验、失败处理及生命周期后接入。没有足够证据时说明缺口，不猜 API。

## 0.x 已核实差异

- 0.1.0 提供独立认证运行时、Google 和可选邮箱认证；0.1.1 增加 Apple 登录验证与撤销队列。
- 0.2.0 增加可选滑动刷新与凭据代次状态；升级涉及宿主数据库迁移。按实际版本文档核实迁移与会话配置，不将这些能力用于 0.1.x。

不要因为发现此库就改动项目依赖；新增依赖遵循项目选型规则。关联 FastAPI 或其他自有包时同时参考可用的对应 Skill。
