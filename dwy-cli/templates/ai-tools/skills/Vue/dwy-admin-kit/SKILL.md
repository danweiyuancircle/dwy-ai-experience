# @dwydev/admin-kit

管理后台模块、路由装配及 AdminShell 布局。项目使用 0.3.0 时可阅读 [0.3.0 接入说明](references/v0/0.3.0.md)；其他版本不能直接套用。

先查项目实际依赖、锁文件与已安装包的声明文件和现有调用；版本范围不是安装版本。核实组件 props、初始化和生命周期后再使用。当前能力索引基于 0.3.0；版本不同可能存在差异。相同版本的源码与接入文档见仓库 `frontend/admin-shell`，其他版本查对应 `@dwydev/admin-kit@版本` 标签；不能用默认分支代替。缺少证据时说明，不猜接口。项目未安装时不自行添加依赖。

0.2.0 重写 AdminShell，并移除旧版内置主题、通知和用户菜单；0.3.0 新增组件、composables、分页列表等子入口，EUI peer 下限为 2.7.2。升级时核实宿主插槽与配套版本，不能把 0.3.0 接口用于 0.1.x。
