# S03025

## 错误代码

S03025

## 报错信息

Only admin can force delete a stream table from the disk.RefId: S03025

## 错误原因

只有管理员有权限执行强制 drop 未加载的流表。非管理员执行该操作会报错。

## 解决办法

- 联系 server 管理员进行操作。
- 或者以 admin 身份登录后再执行强制 drop。
