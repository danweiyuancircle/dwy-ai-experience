# S10008

## 错误代码

S10008

## 报错信息

keyColumn must be a string or a string vector indicating the name of the key
columns.RefId: S10008

## 错误原因

提供了不合法的分组列列名参数。注意：分区列必须为字符串/字符串数组，且名称和输入表的一个或几个列名相对应。

## 解决办法

按照要求使用合法的分组列名。
