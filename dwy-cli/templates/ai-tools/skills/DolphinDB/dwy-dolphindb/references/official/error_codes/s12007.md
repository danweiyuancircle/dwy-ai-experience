# S12007

## 错误代码

S12007

## 报错信息

The specified index type is not supported. Supported types are “bloomfilter” and
“zonemap” (default, cannot be manually specified).RefId: S12007

## 错误原因

用户指定了当前系统不支持的索引类型。

当前系统支持的索引类型包括：BloomFilter、ZoneMap。

## 解决办法

指定正确的索引类型。
