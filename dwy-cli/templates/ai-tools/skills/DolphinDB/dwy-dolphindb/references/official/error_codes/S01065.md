# S01065

## 错误代码

S01065

## 报错信息

The column [" + columnName + "] to be modified cannot be partitioning column. RefId:
S01065

## 错误原因

在对分布式表应用 `replaceColumn!`、`dropColumns!` 或
`rename!` 函数时，要修改的列 *colName* 不能是该表的分区列，否则会出现该报错。

## 解决办法

在对分布式表应用 `replaceColumn!`、`dropColumns!` 或
`rename!` 函数时，*colName* 只能指定为非分区列。
