# S07002

## 错误代码

S07002

## 报错信息

Cannot insert record with duplicate key 'x' because the table enforces uniqueness on
column(s) 'xx'. RefId: S07002

## 错误原因

如果向建有 unique 索引的 OLTP 表中插入数据时，索引键包含的所有字段不能与现有数据重复。

## 解决办法

检查待插入 OLTP 表的数据，确保索引键包含的所有字段与现有数据没有重复。
