# 3.0.4

## 3.0.4.2

### 缺陷修复

- 修复在部分情况下连接断开后未自动重连的问题。

## 3.0.4.1

### 缺陷修复

- 修复 `Session.subscribe` 方法在未传入 *userName* 和
  *password* 参数时报错的问题。
- 修复在集群环境下，因异常解析集群重定向信息导致重连耗时过长的问题。
- 在使用 PROTOCOL\_ARROW 协议进行数据通信时可能发生的内存泄漏问题。

## 3.0.4.0

### 新功能

- 新增 `SimpleDBConnectionPool` 用于创建连接池并管理连接。
- `TableAppender`、`TableUpserter`、`PartitionedTableAppender`
  和 `MultithreadedTableWriter` 支持向 Orca 中的流表插入数据。
- `MultithreadedTableWriter` 新增 *tryReconnectNums*
  参数，用于设置自动重连的次数。
- `DBConnectionPool` 和
  `MultithreadedTableWriter` 新增 *usePublicName*
  参数，支持在集群环境下使用节点的 publicName 作为连接地址。

### 功能优化

- 优化部分日志输出。
- 优化部分情况下重连会占用 GIL 锁的问题。
- 优化 Session 连接信息及时更新机制。
- 优化执行脚本的限制：当设置了 *fetchSize* 时，未完成数据读取前禁止执行其他脚本。

### 缺陷修复

- 在设置 `tryReconnectNums=1` 时，无法成功连接集群。
