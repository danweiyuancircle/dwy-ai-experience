# S09006

## 错误代码

S09006

## 报错信息

JIT: Scalar assignment from vector requires scalar indexing.RefId: S09006

## 错误原因

进行左边为标量、右边为向量的赋值操作时，向量需要通过标量索引。如 `a = b[c]`，a 为标量、b 为向量，要求 c 为标量。

## 解决办法

按照要求修改参数。
