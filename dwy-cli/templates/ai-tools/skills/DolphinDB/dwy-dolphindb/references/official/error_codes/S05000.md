# S05000

## 错误代码

S05000

## 报错信息

The input matrix is singular and cannot be inverted. RefId:S05000

## 错误原因

参与求逆的矩阵是奇异的（或称为非可逆的）。

## 解决办法

避免对奇异矩阵的求逆。
