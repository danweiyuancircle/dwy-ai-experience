# updateStreamGraphUserTickets

## 语法

`updateStreamGraphUserTickets()`

## 详情

在 ORCA 中使用 UDF Engine 时，系统会自动保存创建流图用户的认证信息，以确保 UDF Engine
中自定义函数的访问权限与该用户的权限一致。当认证信息失效时，可调用此函数更新认证状态。

## 参数

无。

## 返回值

无。
