# 通知头像资源

业务头像属于 dwy-webhooks，dwy-notify 不提供默认 Logo。PNG 用于 Discord 的公网 avatar_url，SVG 保留可编辑源。图形来自 Lucide 0.468.0，固定上游提交 f12b0de177fbc2a6795e99be065887e72b237123，保留同目录 LICENSE.lucide.txt。

- purchase：购买、续订、退款
- review：应用审核与版本状态
- report：经营日报与周报
- email：邮件事件
- general：其它系统事件

默认公开地址固定到本仓库只包含资产的 Git 提交 SHA；已有资产 URL 保留。应用可覆盖为自己的 HTTPS 地址，不使用会过期的签名链接。
