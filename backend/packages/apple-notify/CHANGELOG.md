# dwy-apple-notify

## 0.1.2

- 家庭共享订阅首次获权、重新获权和续期使用独立标题，避免误认为新增购买。
- 家庭共享价格标明“无新增付款”；保留本人购买、到期、退款、撤销及关闭续订的事件含义。

## 0.1.1

- 日报、周报固定展示全部指标及地区、来源 Top 3；缺失值逐项显示“无数据”，移除笼统的待发布尾注。
- 保留真实零值、金额币种校验、完整七天汇总与期末订阅快照口径；采集状态和调度策略不变。

## 0.1.0

- 从 dwy-webhooks 独立 Apple 购买、ASC 审核、评论与经营报表通知，平台 SDK 按能力 extra 安装。
- 公共投递、队列租约、部分重试与展示快照统一复用 dwy-notify，领域模块显式传入自己的名称和头像预设。
- analytics 固定统计发送时区日期前两天，默认北京时间 08:30；周一周报保持相同截止逻辑，不暴露外部天数参数。
- 保留原官方回调 URL、来源标识、队列表结构与去重合同；不接管应用权益和业务事务。
