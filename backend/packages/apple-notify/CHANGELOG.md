# dwy-apple-notify

## 0.1.6 - 2026-11-07

- 支持通过已验签的 Apple App 交易查询首次获取 App 的平台，并在购买通知中按需展示；该字段不代表本次内购的设备。

## 0.1.5 - 2026-11-06

- 新增独立 `ratings` extra，按配置时区与小时/分钟每日读取各应用、地区的公开聚合评分，不需要 Apple 账号密钥。
- 保存每日快照，在同一日报展示日、7 天前、上月同日（月末截断）的评分数与累计均分变化；缺历史或采集失败不补零，无变化也汇报。
- 复用持久租约与通知队列，保证快照和日报原子提交；投递重试不重复采集，撤销应用会抑制包含它的旧汇总。
- 覆盖有界外部 JSON、午夜跨日失败汇报、取消恢复与独立安装验收；原购买、审核、文字评价和经营日报保持原有配置与行为。

## 0.1.4

- 经营报表 GET 连接、读写超时和远端断流最多尝试三次，间隔 1、2 秒；POST、HTTP 状态和无效载荷不重试，保留整轮 240 秒预算与取消语义。
- 请求诊断记录关联号、操作、尝试次数、连接/TLS/响应阶段、状态、异常类型及耗时；不记录 URL、请求头、trace 参数、异常正文或响应内容。
- 采集日志补充整轮关联号、逐日进度、失败统计日和总耗时，便于区分单次请求故障与整轮超时。

## 0.1.3

- 修复实际订阅事件报表 Event Group/Event Name 列名及 Paid subscription start 分类解析，保留文档字段形式支持并拒绝歧义重名列。
- 订阅存量直接按 State Metric 分类，不再依赖实际文件可能缺少的 State Metric Grouping；未知类别仍显示无数据。
- 采集失败日志保留安全的底层错误码和超时原因，不记录异常原文或签名下载地址。

## 0.1.2

- 家庭共享订阅首次获权、重新获权和续期使用独立标题，避免误认为新增购买。
- 家庭共享价格标明“无新增付款”；保留本人购买、到期、退款、撤销及关闭续订的事件含义。

## 0.1.1

- 日报、周报固定展示全部指标及地区、来源 Top 3；缺失值逐项显示“无数据”，移除笼统的待发布尾注。
- 保留真实零值、金额币种校验、完整七天汇总与期末订阅快照口径；采集状态和调度策略不变。

## 0.1.0

- 从 dwy-webhooks 独立 Apple 购买、ASC 审核、评论与经营报表通知，平台 SDK 按能力 extra 安装。
- 公共投递、队列租约、部分重试与展示快照统一复用 dwy-notify，领域模块显式传入自己的名称和头像预设。
- analytics 固定统计发送时区日期前两天，默认北京时间 08:30；周一周报保持相同截止逻辑，不暴露外部天数参数。
- 保留原官方回调 URL、来源标识、队列表结构与去重合同；不接管应用权益和业务事务。
