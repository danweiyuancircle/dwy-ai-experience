# 邮件平台事件通知测试

- 真实 Svix HMAC 签名接收、可配置路径/来源作用域、通知只含安全元数据。
- 缺失、篡改、过期、未来时间、错误签名及超长事件 ID 均在 sink 前拒绝。
- 事件筛选先于无关数据解析；已验签但不合法的数据返回 400；真实流大小限制 64 KiB。
- 自定义 sink 只有布尔成功才确认；投递错误返回 502，其它异常不伪装成功。
- 默认 relay 失败后允许上游重试，成功后去重；邮件名称/固定头像预设和应用覆盖/清除头像。
- 安装保留宿主 lifespan 和异常处理器，重复安装和缺通知目标在注册前拒绝。
- 配置字段限制与 signing secret 脱敏；wheel 基础导入不加载 Resend/Apple 或旧 Webhook 包。
