# 首批基础组件规格

日期：2026-11-12。版本：第二版设计基线。状态：用于实施的规格，不表示下列所有 API、资源和行为已经实现。

默认值统一引用 `ios/Docs/DESIGN_TOKENS.md` 第 4 节；配置与本地化遵循 `ios/Docs/DESIGN_CONFIGURATION.md`。这里定义结构、状态、事件和验收，避免每个页面自行决定同一种控件行为。

## 1. 全组件共通契约

- iOS 与 Mac 独立实现，组件命名可保留 IOS/Mac 前缀；语义一致不要求类型或视图字节级相同。现有 Mac 原型名称不是全部稳定公共接口。
- 可本地化标题/说明/可访问名称保留 LocalizedStringKey、LocalizedStringResource 或 Text/Label builder；用户原文及已解析 String 使用明确路径。库自身资源不从消费 App main bundle 猜测。
- 使用原生 ButtonRole、Binding、tag、controlSize、keyboardShortcut 等既有能力，避免新造字符串选项、万能 ViewModel、注册中心或状态字典。
- 状态由明确拥有者提供；UI 只展示和触发动作，不发请求、不写业务持久化、不推断权限/购买/任务成功。
- 每个可点击控件均有可访问名称、完整命中范围和平台适用的键盘路径；颜色不能成为状态的唯一线索。
- 正常交互、VoiceOver、长文案/字号、禁用/忙碌和取消均须验证。公开承诺的行为必须有可运行示例与必要测试。

### 状态共存规则

| 组合 | 明确行为 |
|---|---|
| disabled + pressed/hover | 不触发业务动作；保留系统禁用语义，不伪造成功反馈 |
| busy + enabled | 展示真实忙碌、保留可访问名称并禁止重复启动；真正可取消时用独立取消动作 |
| destructive + brand accent | 原生危险 role/语义优先，不能被品牌色覆盖 |
| selected + focus | 两种含义同时可识别；焦点移动不等于改写选择 |
| invalid + focus | 保留焦点与可读错误说明，输入仍可修正；是否允许提交由业务判定 |
| reduced motion/transparency/高对比 | 系统偏好优先；不能为了固定视觉强制关闭它们 |

## 2. 操作按钮与图标按钮

**结构**：可本地化 Label（文字、SF Symbol 或调用方图片）、可选进度展示、原生 Button。Pro 锁标和购买判断仍由产品组合。

**变体**：primary / secondary / plain；危险动作通过原生 destructive role，不增加一套颜色枚举。默认 secondary；文字自然宽度。iOS 表单主动作可由明确组合层铺满，Mac 默认 hug 标题。

**几何与外观**：引用 size.iconHit / action、typography.body、spacing.controlGroup；图标只引用 glyph 规格，实际命中按外部边界验证。内容区使用标准控件，浮动操作用适用玻璃样式，系统 toolbar 避免再叠一层玻璃。

**事件**：action 每次有效原生激活调用一次；业务提供 isBusy，原生 disabled 继续可用。组件不自动注册全局快捷键，不把所有 primary 绑定 Enter 或所有取消绑定 Esc；默认操作由真实宿主唯一指定。

**状态**：normal / press / focus / hover（适用）/ disabled / busy / destructive。busy 标签保持可访问，不用 opacity(0) 隐藏全部名称。不同主次层级在默认品牌色下仍可区分。

**验收**：鼠标/触摸/键盘激活、背景边缘命中、图标-only 名称、长标题、busy 连点、禁用、危险色、主次层级与焦点。用户图片由消费方提供，不要求库读取 App 资源名。

## 3. 动作菜单

**结构**：明确触发 Label + 原生 Menu 内容 builder。菜单内使用原生 Button、Section、Divider、Toggle/子菜单，保留原生角色和当前值语义。

**默认**：标准尺寸、自然宽度，触发标签使用 secondary 操作语义；Mac toolbar 与 floating 由区域声明场景。纯图标触发也必须有可访问名称。

**事件**：打开菜单不执行选项动作，只有有效选择才调用对应动作；取消不调用动作。菜单项禁用继续保留禁用语义。菜单不持有应用路由或设备会话。

**验收**：打开、选择、取消、禁用项、分组、危险项、键盘遍历与读屏；窗口/滚动位置变化后仍对应入口。不可在 Menu label 内嵌套第二个 Button 形成竞争命中。

## 4. 单选与分段选择

**结构**：原生 Picker，强类型 Selection: Hashable、Binding<Selection> 和带稳定 tag 的原生选项；Optional 选择必须有对应 nil/占位策略。

**默认**：普通单选走平台适用的 menu 呈现，分段用独立明确变体。Mac 的设置值直接用 Picker.menu，不为统一外观再手写选值 Menu。iOS 保留系统尺寸类别适配。

**事件**：只在用户完成有效选值时回写；外部 Binding 更新也立即显示。打开、取消、焦点移动、候选重排不隐式写业务。当前选择被删除时，不自动改成第一项；由业务提供有效候选或 nil/未匹配状态，控件保持可识别状态且不静默提交。

**状态**：normal / selected / focus / disabled / disabled option / empty / unmatched。候选空与加载是不同状态，加载状态从外部提供。

**验收**：双向绑定、枚举 tag、Optional、禁用项、候选新增/重排/删除、空态、取消、长选项、窄窗与外接键盘。不会因选项身份变化误写另一个值。

## 5. 文本、密码与搜索

**结构**：原生 TextField / SecureField + 本端字段外壳；可选的表单标签、说明、错误属于 Field 组合。搜索提供装饰图标、文本和有名称的清空动作。

**默认**：单行外壳使用 size.field/search，语义正文；搜索清空只清当前绑定，不删历史、不触发网络或删除数据。密码使用 SecureField，不转成普通 TextField 复制展示。

**事件**：即时文本 Binding，保留原生 onSubmit、focus、输入配置和编辑快捷键。onSubmit 与失焦不是一个事件。库不擅自 trim、截断、改大小写、保存历史或填写业务默认值；业务校验不能改写正在组合的中文。

**状态**：normal / focus / disabled / invalid。错误文本优先于普通 hint，仍允许修正；焦点及错误不只用描边颜色表达。禁用字段不能继续编辑，但原文仍应可读。

**验收**：中文 marked text、粘贴、原文空白、长文本、错误修正、Return/Tab、密码自动填充与安全输入（适用时）、键盘避让、可访问标签与语言切换。密码和敏感输入不进入日志或示例数据。

## 6. 开关与适用的复选框

**结构/默认**：iOS 使用原生 switch。Mac 的 Switch 明确使用 .switch；桌面表单需要复选框时使用明确的 Checkbox 组合，不能让同名开关因空 label 变成难辨认的方点。

**事件**：Binding<Bool> 双向；修改事件只表达用户选择，不自动执行后台服务。需要网络确认时由业务提供 pending/错误与最终值，组件不假定写入成功。

**状态**：on/off、focus、disabled；异步 pending 由真实流程决定是否暂禁用并显示说明。菜单里的 Toggle 沿用系统菜单勾选语义，不强行画成 switch。

**验收**：切换、外部回写、禁用、空视觉标题但有可访问名称、长说明、键盘、菜单上下文与读屏状态。

## 7. Mac 建议下拉

**结构**：原生文本编辑器、展开按钮、可滚动建议承载。数据由调用方提供，字符串历史可按稳定文本去重并保序；若业务有不同对象同名，须使用稳定 ID 的明确选项模型，不能把名称当身份。

**默认**：使用 search 尺寸，建议文本单行可辨认；列表承载按窗口/可见区域自适应，不固定绝对 offset 到父 ScrollView 外。优先评估成熟原生能力，保留“不自动改写组合输入”的约束，不为每个页面自制悬浮层。

**键盘与事件**：

- 输入只更新 Binding/筛选；非输入法组合期间 Down 从第一项、Up 从末项开始，后续循环导航，选中项保持可见。
- 输入法仍有 marked text 时，上下键和 Esc 先交原生编辑器，不抢输入法候选操作。
- Return 提交当前有效建议，否则提交原文；点建议回填并提交一次。Esc 收起建议，不抹掉已输入内容，不触发提交。
- 失焦结束编辑与显式提交分别表达；默认不因失焦触发 onCommit。业务若需失焦保存历史，通过明确的编辑结束回调适配，不能重复生成一次提交。
- 候选变化清理失效高亮但不自动替用户选值。只有完成有效选择才提交，取消/关闭不写历史。

**验收**：键盘/鼠标/VoiceOver、输入法、长候选与动态更新、空结果、失焦重入、窗口上下边缘、滚动容器裁剪、缩放移动与取消；不能用增加 zIndex 冒充越过宿主裁剪。当前 EComboBox 原型尚不满足这些全部门槛，不得直接发布为稳定组件。

## 8. 表单行与动作组

**结构**：标题、控件槽、hint/error；主次动作通过平台 ActionGroup/表单动作区组合。默认 error 优先于 hint，文字可换行，Label 与编辑器可访问关系明确。

**默认布局**：iOS 使用平台 pageInset、fieldLabel、formRow，主动作按明确移动端表单铺满；Mac 主次动作右对齐、自然宽度。字段内容可滚动，关键提交/取消保持可达；不固定整张表单高度裁掉长内容。

**事件**：不执行表单校验/保存，也不因展示错误自动清值、移焦或关闭。Enter/Esc 的唯一所有者由宿主定义，动作组不注册全局快捷键。

**验收**：长标签/错误、字号、键盘、滚动、禁用/忙碌、多个表单/窗口的默认动作不互相抢占。floating 组仅对相关玻璃形状统一采样，不把正文放进容器。

## 9. 轻提示、状态标签与内联错误

**结构**：可访问的消息/状态文字、可选图标及明确动作；success/warning/error 是语义，不是任意颜色。提示采用原生或适合的本端呈现。

**生命周期**：非关键成功 toast 使用 tokens 中的计时策略；初始非空消息也能显示。新消息取消旧计时，清空/宿主销毁取消待处理更新；读屏公告与交互焦点按辅助功能要求处理。错误、确认、需操作 notice 不自动套用短计时。

**事件与模态**：普通提示默认非模态；复制成功等不使整个 toolbar 永久禁用。模态确认由宿主明确管理，不以“当前有消息”一律阻断所有交互。

**验收**：初始消息、快速替换、重复/不同消息、取消计时、释放、长文本、读屏、窗口遮挡与后续动作恢复；重要失败持续可读，状态不只靠颜色。

## 10. 进度、任务状态与内容占位

**结构**：外部明确提供 idle / loading / success / empty / failure，进度区分 indeterminate 与 determinate；可取消能力与取消动作同时由业务提供。不根据空数组猜 loading，不把有数据等同于成功。

**数据与事件**：进度值的非有限/越界错误由外部数据边界拒绝并转成明确错误状态；UI 不显示伪造百分比。取消回调不意味着取消完成，完成/失败由真实任务回写。单纯 busy 不让不相关窗口或后台任务失效。

**默认**：系统 ProgressView 优先；错误/空态可有一个明确后续动作，文案与动作来自产品。占位不模拟真实业务成功记录，不对读屏重复朗读无意义装饰。

**验收**：不定/定量进度、重复启动、取消进行中/取消完成、失败后重试、原窗口销毁、多任务隔离及读屏。组件不会启动任务、隐式重试、吞错误或擅自降级为成功。

## 11. 导航局部与原生呈现承载

**iOS**：返回与关闭分开；优先原生 Navigation/Sheet。自定义页头标题可截断，正文可换行，触点/键盘路径符合本端规范。popover/confirmationDialog 挂实际触发入口，18.0/18.1 与尺寸类别差异按 iOS 规范。

**Mac**：toolbar、窗口与焦点保持原生约束。公共工具栏操作组不拥有 tab 保活、全局快捷键或窗口注册；自定义弹层如果不能明确处理蒙层、首次点击、焦点恢复和取消，不从 ADBox 整体搬进库。

**验收**：窗口/列表/触发目标变化、屏幕边缘、取消再开、Enter/Esc、输入焦点、打开/关闭后操作栏恢复。确认作用在真实原对象；切设备或账号不复用错误上下文。

## 12. 首批交付检查表

| 阶段 | 必需证据 |
|---|---|
| API | 类型化、可本地化文本、原生语义、状态/回调所有权、独立公开示例 |
| 默认设计 | 引用本端 tokens 和系统策略，所有公开变体/状态在展示应用可达 |
| 行为 | 绑定、提交/取消、焦点/输入法、无效/动态候选、生命周期等实际风险测试 |
| 视觉/可访问 | 长文案、字号、明暗、对比、减少透明度/动态效果、键盘与 VoiceOver |
| 平台 | iOS 18 + 当前最新支持版，相关玻璃场景 26；Mac 26；具体现有差异按需补测 |
| 消费方 | 新项目模板与 ADBox 迁移入口都使用同一已发布版本，不复制库实现或提交本机路径 |
