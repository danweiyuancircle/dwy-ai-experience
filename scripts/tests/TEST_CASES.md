# 私有发布回归

执行：`python3 -m unittest discover -s scripts/tests -p 'test_private_release.py'`。

| 测试 | 保护行为 |
| --- | --- |
| 包级 private / 旧工作流 | 防止新代码通过旧公共发布入口泄露 |
| GitHub 实际可见性 | 公共仓库返回 false 时拒绝发布或读取 |
| 完整性 | 修改真实产物字节后校验失败 |
| 外部文件清单 | 拒绝目录逃逸、未列出的包、无效标签和源提交 |
| 产物目录 | 拒绝空目录和环境文件 |

外部 GitHub 查询使用固定响应替身；摘要、文件与清单验证使用真实临时目录。真实私有访问和发包下载由发布工作流及发布后的安装 smoke 验证。
