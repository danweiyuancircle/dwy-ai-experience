# 项目内业务基础组件

本目录属于② Features 功能层，编入 macOS App target，不是新增层级或强制包装模块，不属于共享的③ BizFoundation。完整规范见 `docs/ARCHITECTURE.md`。

- `DesignKitMac` 已满足需求时直接使用，禁止逐个再套同功能组件或复制实现。
- 有业务语义、产品样式或交互组合需求时，在这里封装业务基础组件，优先组合共享组件；不必等到出现第二个调用方。
- 共享组件不存在或不足以支撑业务效果时，允许用 SwiftUI/AppKit 自行实现所缺部分，UI 收敛在对应业务组件中，不散写到各页面。
- 通过值、Binding 和动作回调连接页面；文件授权、危险操作、任务取消、权益、持久化与窗口生命周期仍归业务/装配层。
- 通用缺口是否回流共享库按真实复用收益与改动成本决定，不要求每次先改库。自行实现的部分由项目负责系统适配、键鼠交互与可访问性验证。
