# S01057

## 错误代码

S01057

## 报错信息

Failed to compact level files, with error code <ret>.

## 错误原因

TSDB在合并 levelfile 时发生错误。

## 解决办法

根据报错中的信息 ret，和出错时 server 的 log，分析原因，并进一步解决。
