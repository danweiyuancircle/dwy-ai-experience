# 3.0.3

## 3.0.3.0

### 功能优化

- 更新支持的 Python 版本范围：由 3.6–3.12 调整为 3.8–3.13 (with-GIL)。
- 新增支持 NumPy 2.x。
- `MultithreadedTableWriter` 新增参数
  *enableStreamTableTimestamp*，用于支持向服务器端已通过
  `setStreamTableTimestamp` 设置时间戳列的流表写入数据。
- `createTable` 已更名为
  `createDimensionTable`，并保留旧名称作为别名。
- Session 和 DBConnectionPool 增加 *parser* 参数用于指定连接后服务器使用的解析器类型。
- 优化断线重连相关日志：将部分原为 INFO 的日志调整为 ERROR 等级，同时将默认日志等级由 INFO 修改为 WARNING。
