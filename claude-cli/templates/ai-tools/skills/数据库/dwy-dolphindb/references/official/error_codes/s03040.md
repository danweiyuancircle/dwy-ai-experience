# S03040

## 错误代码

S03040

## 报错信息

Failed to deserialize events due to incompatible event schema. Expected: <xxx>.
Actual: <xxx>. RefId: S03040

## 错误原因

CEP 引擎会按照定义的 eventSchema 反序列化字节流。当序列化中定义的 eventSchema 和 CEP 引擎定义的 ecentSchema
不一致时，会出现该报错。

## 解决办法

检查传入的 event 类型和 CEP 定义的 eventSchema 是否一致。
