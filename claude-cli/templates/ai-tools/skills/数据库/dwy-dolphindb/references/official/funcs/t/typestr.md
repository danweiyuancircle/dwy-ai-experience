# typestr

## 语法

`typestr(X)`

## 详情

返回一个表明 *X* 的数据类型的字符串。详细信息参见 [数据类型](../../progr/data_types.html)。

## 参数

**X** 可以是系统支持的任意数据类型。

## 返回值

STRING 类型标量。
