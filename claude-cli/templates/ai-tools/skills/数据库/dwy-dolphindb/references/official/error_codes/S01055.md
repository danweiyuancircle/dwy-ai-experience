# S01055

## 错误代码

S01055

## 报错信息

Failed to <xxx>, with error code <xxx>, errno <xxx>. RefId:S01055

## 错误原因

在写入数据时，遇到磁盘满、无权限等问题，会出现该报错。

## 解决办法

这是操作系统的报错，参考 [Chromium OS Docs - Linux Error Number Table
(errno)](https://chromium.googlesource.com/chromiumos/docs/+/master/constants/errnos.md) 进行排查。在解决操作系统问题后，尝试通过 `flushTSDBCache`
将数据写入数据库。
