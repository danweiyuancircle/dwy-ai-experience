# S12005

## 错误代码

S12005

## 报错信息

The database is not found during redo log replay. Please contact technical
support.RefId: S12005

## 错误原因

回放 redo log 的时候，该事务操作的数据库不存在。

## 解决办法

定位过程较为复杂，请联系技术支持。
