# S01050

## 错误代码

S01050

## 报错信息

[chunkRecovery]: CRC32 check failed for file <filePath>. The saved checksum
<xxx> does not match the current checksum <xxx>.

## 错误原因

在 recovery 过程中列文件的校验和不一致。

## 解决办法

检查该 chunk 其他副本列文件校验和是否一致，结合日志进一步分析列文件损坏原因。
