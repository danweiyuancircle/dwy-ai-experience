# S01035

## 错误代码

S01035

## 报错信息

[asyncReplication] Failed to write task <tid>, with error: xxx.

## 错误原因

异步复制主集群数据节点需要将异步复制任务数据持久化，在持久化写入时出现了问题。

## 解决办法

首先根据具体的错误信息进行排查，如是否磁盘空间已满，是否无权限写入等。

解决了写入问题之后，可以根据错误信息中的 tid 查找对应的任务，在确保正确性的情况下将该任务跳过。
