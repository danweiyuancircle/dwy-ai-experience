# enableQueryMonitor

## 语法

`enableQueryMonitor()`

## 详情

启用监控查询任务状态的功能。系统默认会开启该功能。

## 参数

无

## 返回值

无。

相关函数： [disableQueryMonitor](../d/disableQueryMonitor.html)
