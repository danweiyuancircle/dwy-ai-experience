# getAllCatalogs

## 语法

`getAllCatalogs()`

## 详情

检索当前所有可用的 catalog。

## 参数

无

## 返回值

返回一个包含 catalog name 的字符串向量。

## 例子

```dolphindb
getAllCatalogs()
//Output:["catalog1", "catalog2", "catalog3"]
```
