# S01000

## 错误代码

S01000

## 报错信息

TSDBEngine BlockedCacheTable::append: Failed to append to the TSDB cache engine due
to xxx. RefId: S01000

## 错误原因

TSDB 在事务 Complete 时写入 Cache Engine 失败。可能是内存不足，造成了 OOM。

## 解决办法

建议通过 `clearAllCache` 函数清理缓存来释放内存。或者在配置中将 *maxMemSize*
设置为更大的值。
