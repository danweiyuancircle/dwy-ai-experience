# 3.00.5

## CSM

首次发布，支持从 CSMAR 获取以下行情数据并写入 DolphinDB 流数据表。（**3.00.5.3**）

- SSEL2\_Quotation：上交所 Level2 十档快照数据。
- SZSEL2\_Quotation：深交所 Level2 十档快照数据。
- SSEL2\_Tick：上交所 Level2 逐笔数据。
- SZSEL2\_Tick：深交所 Level2 逐笔数据。

## httpClient

### 故障修复

- 修复无法通过 QQ 邮箱发送邮件的问题。（**3.00.5.7**）

## HBase

### 新功能

- `load` 接口新增参数 *scanOptions*，用于透传 HBase Thrift TScan
  参数，控制扫描行为。（**3.00.5.6**）

### 功能优化

- 未设置 `connect` 的 *isFramed*
  参数时，系统将自动探测传输协议。（**3.00.5.7**）

## input

首次发布，支持自动识别数据压缩格式（目前支持 zstd 和 gzip）并解压数据。（**3.00.5.3**）

## kafka

### 功能优化

后台订阅模式下支持获取消息发送时间。（**3.00.5.2**）

## MDL

### 新功能

- 支持订阅中证、沪深债券、北交所债券等数据。（**3.00.5.4**）
- 支持订阅香港股票快照 v2 数据。（**3.00.5.2**）

### 故障修复

修复 `getHandleStatus` 获取的连接状态不正确的问题。（**3.00.5.6**）

## mqtt5

新增 mqtt5 插件，支持 MQTT 5.0 协议和加密通信功能。（**3.00.5.7**）

## OrderManagementEngine

首次发布，支持插入行情、委托下单、订单撮合及持仓管理的功能。（**3.00.5.7**）

## QuickFix

首次发布，支持实时接收并解析 FIX 协议报文，获取银行间市场现券交易行情，并将数据异步写入 DolphinDB 流数据表。（**3.00.5.3**）

## redis

### 故障修复

修复解析收到的二进制数据被错误截断的问题。（**3.00.5.2**）

## signal

### 新功能

- 新增 `angle` 接口，用于返回复数的角度。（**3.00.5.7**）

## xgboost

### 新功能

- 新增对 Linux ARM 的支持。（**3.00.5.5**）

## windTDF

### 功能优化

优化 WindTDF 插件订阅行情时的报错信息。（**3.00.5.7**）
