# 注释

双斜杠//用于单行注释，系统忽略双斜杠后面该行的所有内容。

/\* ...... \*/ 用于多行注释，位于/*和*/中间的所有代码将被看做为注释。

## 语法

```dolphindb
// 这是一句注释

// output
/*
这是一段注释。
这段注释不会被执行。
*/
```
