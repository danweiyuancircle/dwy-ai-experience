# S01015

## 错误代码

S01015

## 报错信息

The number of columns of the current table must match that of the target table.
RefId:S01015.

## 错误原因

使用 `append!` 函数写入 DFS 表时，写入表与被写入表列数不匹配。

## 解决办法

用 `schema` 函数检查写入表的列数是否与目标维度表或分区表的列数匹配。
