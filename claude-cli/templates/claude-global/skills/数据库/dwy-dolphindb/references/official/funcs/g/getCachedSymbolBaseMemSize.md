# getCachedSymbolBaseMemSize

## 语法

`getCachedSymbolBaseMemSize()`

## 详情

获取引擎中 SYMBOL 类型的字典编码的缓存大小，单位是字节。

## 参数

无

## 返回值

返回一个长整型标量。
