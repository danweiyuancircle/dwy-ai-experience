# 谓词

自2.00.9 版本起，DolphinDB支持 SQL 的以下谓词：

- `not`
- `is null`
- `is not null`
- `between and`
- `exists`
- `in`
- `like/LIKE`
- `notLike/NOTLIKE`
- `notBetween/NOTBETWEEN`
- `notIn/NOTIN`
