# S01042

## 错误代码

S01042

## 报错信息

[asyncReplication] Failed to deserialize the metadata of task <tid>, with error:
xxx.

## 错误原因

异步复制从集群节点反序列化任务元数据失败。

## 解决办法

通常为网络问题导致，请使用函数 [startClusterReplication](../funcs/s/startClusterReplication.html) 重试。
