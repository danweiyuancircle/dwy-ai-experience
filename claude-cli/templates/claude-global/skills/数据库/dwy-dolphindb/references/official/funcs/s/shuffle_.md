# shuffle!

## 语法

`shuffle!(X)`

## 详情

`shuffle!` 是 `shuffle`
的原地计算的版本。它们的唯一区别在于：`shuffle!` 会将结果赋值给
`X`，因此在执行后会改变 `X` 的值。
