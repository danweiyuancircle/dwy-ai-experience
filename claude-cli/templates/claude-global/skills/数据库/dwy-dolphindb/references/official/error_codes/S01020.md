# S01020

## 错误代码

S01020

## 报错信息

The specified partitions must already exist in the database. RefId:S01020

## 错误原因

通过分区方式备份时，如果备份的表中不存在参数 *partition* 指定的分区，该错误抛出。

## 解决办法

1. 使用 `pnodeRun(getTabletsMeta)` 查看表中存在哪些分区
2. 修改备份中的 *partition* 参数
