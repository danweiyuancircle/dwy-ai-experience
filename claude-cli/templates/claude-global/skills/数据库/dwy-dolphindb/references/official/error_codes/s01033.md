# S01033

## 错误代码

S01033

## 报错信息

Failed to write to TSDB editlog in replaceTableRecord with I/O error:
<errMsg>.RefId: S01033

## 错误原因

TSDB 进行 update、delete 等操作时，写入 TSDB EditLog 失败。

## 解决办法

根据具体错误进行排查，如是否遇到磁盘满、无权限访问文件等问题。解决后可进行重试。
