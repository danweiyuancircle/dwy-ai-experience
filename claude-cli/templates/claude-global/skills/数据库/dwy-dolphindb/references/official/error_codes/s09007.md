# S09007

## 错误代码

S09007

## 报错信息

JIT: Right operand of 'cast' must be a constant.RefId: S09007

## 错误原因

`cast`（`$`）操作符的右边值只能是常量，如 INT、LONG
等类型常量。比如下方脚本是不被支持的：

```dolphindb
@jit
def demo() {
  a = 1
  type = LONG
  a$type
}
demo()
```

## 解决办法

按照要求修改参数。比如：

```dolphindb
@jit
def demo() {
  a = 1
  a$LONG
}
demo()
```
