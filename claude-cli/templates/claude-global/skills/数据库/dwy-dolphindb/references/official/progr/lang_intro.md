# DolphinDB 脚本语言

DolphinDB 脚本编程涉及的核心概念包括：数据类型与形式、对象、运算符、编程语句、数据操作、函数化编程、文件操作和 SQL 语句。

值得注意的是，DolphinDB 脚本语言是大小写敏感的，所有标识符（如变量、函数名、类名）及保留字（关键字）严格区分大小写。
