# int128

## 语法

`int128(X)`

## 详情

把字符串转换为 INT128 类型。

## 参数

**X** 是一个字符串标量或向量。

## 返回值

INT128 类型标量或向量。

## 例子

```dolphindb
a=int128("e1671797c52e15f763380b45e841ec32")
```

返回：e1671797c52e15f763380b45e841ec32

```dolphindb
typestr(a);
```

返回：INT128
