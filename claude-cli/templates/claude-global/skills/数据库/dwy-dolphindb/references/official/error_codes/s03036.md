# S03036

## 错误代码

S03036

## 报错信息

The CEP engine ‘xxx' failed to call function 'xxx’, with error: xxx. RefId:
S03036

## 错误原因

CEP 引擎在事件匹配成功后会调用回调函数，若回调函数脚本存在错误，则会抛出异常。

## 解决办法

根据具体的错误信息调整回调函数里的代码。
