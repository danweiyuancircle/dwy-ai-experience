# S05009

## 错误代码

S05009

## 报错信息

The scale of Decimal should be an integer. RefId: S05009

## 错误原因

在使用 DECIMAL 数据类型时，指定的 *scale* 必须为整型标量，否则就会报该错误。

下例展示部分错误与正确的操作。

```dolphindb
// 创建 decimal 类型的向量
v = array(DECIMAL32("2"))  // Error
v = array(DECIMAL32(2))  // Ok
```

## 解决办法

*scale* 必须为整型标量。
