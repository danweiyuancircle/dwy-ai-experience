# S02005

## 错误代码

S02005

## 报错信息

Unrecognized column name. RefId:S02005

## 错误原因

查询的列在表中不存在。如以下场景，在表 `t` 不存在查询的 `x` 列，会出现该报错。

```dolphindb
n = 10000
type = take(1..10, n)
sys = take(char('A' + 0..3), n)
t = table(type, sys)
select x from t; // throw exception
select sys from t; // OK
```

## 解决办法

检查表中是否存在查询的列，或者是否将列名写错。
