# S01071

## 错误代码

S01071

## 报错信息

The transaction <tid> has expired. It will be rolled back without resolution.
RefId: S01071

## 错误原因

当控制节点上的事务因超时未能完成时，无需进入决议流程，而是直接执行回滚操作。这是事务处理中的常规日志信息，无需额外处理。

## 解决办法

无
