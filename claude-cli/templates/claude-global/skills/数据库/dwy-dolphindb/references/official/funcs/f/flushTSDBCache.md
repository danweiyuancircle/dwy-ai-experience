# flushTSDBCache

## 语法

`flushTSDBCache()`

## 详情

将 TSDB 引擎缓冲区里已经完成的事务强制写入数据库。请注意，使用该函数前，需配置
*TSDBCacheEngineSize*。

## 参数

无

## 返回值

无
