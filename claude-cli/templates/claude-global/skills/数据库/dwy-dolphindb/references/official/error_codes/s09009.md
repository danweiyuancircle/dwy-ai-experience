# S09009

## 错误代码

S09009

## 报错信息

JIT:Inferring return type failed. The return value cannot be NULL.RefId: S09009

## 错误原因

JIT 函数中不允许使用无返回值的 return。例如下方用法会报错：

```dolphindb
@jit
def demo() {
	return
}
demo()
```

## 解决办法

按照要求修改函数。
