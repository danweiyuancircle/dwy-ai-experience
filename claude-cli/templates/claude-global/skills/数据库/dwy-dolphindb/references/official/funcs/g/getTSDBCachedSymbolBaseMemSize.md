# getTSDBCachedSymbolBaseMemSize

## 语法

`getTSDBCachedSymbolBaseMemSize()`

## 详情

获取 TSDB 引擎中 SYMBOL 类型的字典编码的缓存大小，单位是字节。

## 参数

无

## 返回值

LONG 类型标量。
