# S03043

## 错误代码

S03043

## 报错信息

No access to table [xxxx]. RefId: S03043

## 错误原因

创建 TimeSeriesEngine 时，当前会话的用户没有写入 *outputTable* 参数指定的输出表的权限。

## 解决办法

联系服务器管理员检查输出表的权限设置，或者为 TimeSeriesEngine 指定其它输出表。
