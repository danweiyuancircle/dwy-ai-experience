# S10000

## 错误代码

S10000

## 报错信息

Shark requires premium license. Contact technical support for trial license
request.RefId: S10000

## 错误原因

使用了不正确的 license。

## 解决办法

- 使用已购买的 Shark license。
- 或者联系 DolphinDB 官方助手，申请 Shark license。
