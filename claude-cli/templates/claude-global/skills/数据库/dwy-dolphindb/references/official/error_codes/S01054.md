# S01054

## 错误代码

S01054

## 报错信息

The column at <columnIndex> to be loaded does not exist. The number of available
columns is <colSize>.

## 错误原因

OLAP 引擎在读取某个列文件的时候，发现列文件不存在。

## 解决办法

查看该目录下其他列文件是否存在，结合出问题时的 log 分析具体原因并进一步解决。
