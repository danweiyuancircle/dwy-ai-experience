# 1.30.0.8

## 新增功能

DBConnectionPool 新增了 `runTaskAsyn`
函数，实现并行异步任务调用接口简化。

## 故障修复

- 修复 `update` 函数 where 条件不生效的问题。
- 修复使用 Python API 异步追加数据时，客户端会 crash 的问题。
- 修复使用 Python API 两次 upload 同一个名字的 named object, 报错该 named
  object 无法找到的问题。
