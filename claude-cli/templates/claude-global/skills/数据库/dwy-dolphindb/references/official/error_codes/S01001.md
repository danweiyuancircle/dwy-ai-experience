# S01001

## 错误代码

S01001

## 报错信息

The column used for value-partitioning cannot contain NULL values. RefId: S01001

## 错误原因

分区方式为 VALUE 的分区列数据中不能含有空值。

## 解决办法

检查并确保写入的分区列数据中不含有空值。
