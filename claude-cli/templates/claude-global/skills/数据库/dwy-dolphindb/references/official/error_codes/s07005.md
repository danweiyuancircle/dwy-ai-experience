# S07005

## 错误代码

S07005

## 报错信息

Strings in key column must not exceed 4096 bytes. RefId: S07005

## 错误原因

字符串类型作为索引的键时，其长度不能超过 4096 字节。

## 解决办法

修改字符串类型数据，确保长度不超过 4096 字节。
