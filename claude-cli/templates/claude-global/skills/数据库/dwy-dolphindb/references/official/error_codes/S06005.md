# S06005

## 错误代码

S06005

## 报错信息

Not allowed to overwrite existing built-in functions/procedures. RefId: S06005

## 错误原因

如果定义一个与系统内置函数同名的函数，会报出这个错误，比如，[now](../funcs/n/now.html)
是内置函数，但定义时使用了与该内置函数同名的 `now()`：

```dolphindb
def now() {  // 报错     
    return "I don't know" 
}
```

## 解决办法

确保自定义函数名称与系统内置函数不重名。
