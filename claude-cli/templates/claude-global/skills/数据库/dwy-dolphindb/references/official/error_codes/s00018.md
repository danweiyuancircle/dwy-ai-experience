# S00018

## 错误代码

S00018

## 报错信息

SSL error: xxx. RefId: S00018

## 错误原因

配置 *enableHTTPS* 后，Web 会使用 HTTPS 协议与 server 通信。在通信过程中，如果产生任何错误，就会显示该 Log。

## 解决办法

根据具体报错的内容，在 [OpenSSL
错误码文档](https://www.openssl.org/docs/man1.0.2/man3/SSL_get_error.html)中查询信息后再进一步分析。若无法解决请联系技术支持。
