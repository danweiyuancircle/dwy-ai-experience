# S09001

## 错误代码

S09001

## 报错信息

JIT: Function passed as the argument to the JIT function can only take integral or
floating-point scalars.RefId: S09001

## 错误原因

JIT 函数的参数为函数时，这个函数参数的标量参数只能是整型或者浮点型。

## 解决办法

按照类型要求修改参数。
