# getExecDir

首发版本：3.00.4，3.00.3.1

## 语法

`getExecDir()`

## 详情

获取 dolphindb 可执行文件所在目录的绝对路径。

## 参数

无

## 返回值

字符串标量。

## 例子

```dolphindb
getExecDir()
// output: /home/dolphindb/server
```
