# 3.0.0

## 3.0.0.2

### 功能优化

- `Session/session`、`DBConnectionPool` 类的
  `run` 接口新增参数
  *disableDecimal*，用于指定在下载数据表时，是否将其中的 DECIMAL 列转换为 DOUBLE 类型。若设置为
  True 则会进行转换，否则不转换。

## 3.0.0.1

### 功能优化

- 优化 `MultithreadedTableWriter` (MTW) 的内存管理。

## 3.0.0.0

### 新增功能

- 新增 Event / Scalar / Vector 等类，支持自定义事件。
- 新增 EventSender 类，支持将事件写入异构流表。
- 新增 EventClient 类，支持从异构流表中订阅事件。

### 功能优化

- `subscribe` 新增参数 *backupSites*,
  *resubTimeout*, *subOnce*，以支持发布端主备节点切换、配置重连间隔。
- 支持上传 pandas
  如下拓展类型：Boolean/Int8/Int16/Int32/Int64/Float32/Float64/String。
- 优化类型注解。

### 故障修复

- 修复使用 Pickle 协议反序列化数据失败的问题。
- 修复订阅如下类型数据出现内存泄漏的问题：STRING, SYMBOL, IP, UUID, INT128, BLOB。
- 修复在特定情况下由于 pandas 版本不兼容导致的 TableAppender 写入时间类型数据不正确的问题。
- 修复上传 NaN 至 DolphinDB 服务端时，NaN 没有转换为 NULL 的问题。
- 修复 TableAppender/TableUpserter/PartitionedTableAppender 在向 DECIMAL
  列写入字符串时引发段错误的问题。
