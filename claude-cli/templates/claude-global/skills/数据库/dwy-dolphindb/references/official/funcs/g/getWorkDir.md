# getWorkDir

首发版本：3.00.4，3.00.3.1

## 语法

`getWorkDir()`

## 详情

获取启动 dolphindb 进程时所在的工作目录的绝对路径。

## 参数

无

## 返回值

字符串标量。

## 例子

```dolphindb
getWorkDir()
// output: /home/dolphindb/server/clusterDemo  
```
