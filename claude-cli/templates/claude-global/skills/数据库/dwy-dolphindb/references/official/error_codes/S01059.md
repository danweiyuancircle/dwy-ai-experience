# S01059

## 错误代码

S01059

## 报错信息

Function getTSDBCompactionTaskStatus is only enabled in DATANODE or SINGLE mode.

## 错误原因

TSDB 相关的运维函数只能在数据节点或单节点执行。

## 解决办法

在数据节点或单节点执行该函数。
