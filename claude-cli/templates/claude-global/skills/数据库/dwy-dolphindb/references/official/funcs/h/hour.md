# hour

## 语法

`hour(X)`

## 详情

返回对应的小时数。

## 参数

**X** 是一个时间标量/向量。

## 返回值

INT 类型标量或向量。

## 例子

```dolphindb
hour(2012.12.03 01:22:01);
```

返回：1
