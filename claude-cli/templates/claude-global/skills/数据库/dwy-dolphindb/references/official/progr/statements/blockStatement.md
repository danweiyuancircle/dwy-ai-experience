# 程序块

DolphinDB 使用花括号{}来指明一个语句块。

## 语法

```dolphindb
{
statement1
statement2
statement3
...
}
```

[doWhile](doWhile.html)
控制语句必须使用块符号。当执行多条语句时，块符号还能在 [if](ifElse.html) 语句中使用。
