# S10002

## 错误代码

S10002

## 报错信息

Failed to detect GPU on the current device.RefId: S10002

## 错误原因

在当前设备中未检测到 GPU。可能原因如下：

- 没有安装 NVIDIA GPU 驱动。
- 安装了与 DolphinDB 不匹配的 CUDA 版本。

## 解决办法

查当前环境，安装正确版本的驱动或 CUDA。
