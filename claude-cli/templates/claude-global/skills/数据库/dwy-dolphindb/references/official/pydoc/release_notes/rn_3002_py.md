# 3.0.2

## 3.0.2.4

### 功能优化

- `subscribe` 的 *filter* 参数支持传入 lambda 字符串。

### 故障修复

- 在使用 PROTOCOL\_DDB 协议下载数据时，如果 BOOL 类型列的长度超过 8192 时，会出现数据异常。

## 3.0.2.3

### 新增功能

- 新增接口 `get_types_from_schema`，支持提取表结构信息。同时扩展
  `__DolphinDB_Type__`，现支持使用 str 类型。

### 故障修复

- 用户未登录时执行 `runTaskAsync`，会反复重连，而未抛出异常。

## 3.0.2.2

### 新增功能

- 新增支持 Python 3.12。
- 新增 Logger package，支持将日志信息和 print 返回的信息输出到指定的位置。
- `MultithreadedTableWriter` 新增参数
  *reconnect*，用于设置在写入时若发生网络连接中断，是否进行自动重连。

### 功能优化

- `subscribe` 中参数 *resubTimeout* 重命名为
  *resubscribeInterval。*

### 故障修复

- 在上传 Decimal 数据时，之前同时存在舍入和四舍五入两种行为。现已将行为统一为四舍五入。
- `tableInsert` 和 `MultithreadedTableWriter`
  接口的写入性能下降。此为 3.0.2.1 引入的问题。
- 在高可用配置下，节点无法正常切换。

## 3.0.2.1

### 新增功能

- 新增 `io` 模块，支持以下序列化和反序列化函数 `dump`,
  `load`, `dumps`,
  `loads`。

### 功能优化

- 优化报错信息。

### 故障修复

- 使用 PROTOCOL\_DDB 协议时，DolphinDB 的 BLOB 类型在 Python 中的对应类型由 str 修正为 bytes。

## 3.0.2.0

### 功能优化

- 增强 `Session.run` 等接口的入参校验。
- `DBConnectionPool`, `Session.connect` 新增参数
  *tryReconnectNums*，用于设置自动重连的次数。
- `DBConnectionPool` 和 `Session` 新增参数
  *sqlStd*，用于指定服务端解析 SQL 时所使用的方言标准。
- 将 `DBConnectionPool` 和 `Session` 的
  *protocol* 参数的默认值由 PROTOCOL\_PICKLE 修改为 PROTOCOL\_DDB。
- 上传 pandas.DataFrame 时， string[pyarrow] 类型的列可以指定为 SYMBOL 类型。
- `Session.connect` 新增参数 *readTimeout* 和
  *writeTimeout*，分别用于指定 API 读和写超时时间。
