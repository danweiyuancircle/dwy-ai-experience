# setLogLevel

## 语法

`setLogLevel(logLevel)`

## 详情

在线设置当前节点的日志文件的等级。设置后，系统只打印当前 logLevel 及以上级别的日志。该命令只能由管理员调用。

## 参数

**logLevel** 日志等级，从低到高可选值为：DEBUG, INFO, WARNING, ERROR。
