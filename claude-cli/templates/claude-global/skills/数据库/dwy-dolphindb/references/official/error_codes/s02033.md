# S02033

## 错误代码

S02033

## 报错信息

The FROM clause must be followed by a table. RefId:S02033

## 错误原因

select 查询的 from 子句必须使用表， join 或子查询。比如下面的例子，from 使用了向量，导致报错：

```dolphindb
vec = [1, 2, 3]
select * from vec
```

## 解决办法

检查脚本中 select 查询的 from 子句是否使用了非法对象。
