# getDatanodeRestartInterval

## 语法

`getDatanodeRestartInterval()`

## 详情

在线获取内存中 DatanodeRestartInterval 的值。该命令只能由管理员在控制节点上调用。

## 参数

无

## 返回值

整型标量。

相关函数：[setDatanodeRestartInterval](../s/setDatanodeRestartInterval.html)
