# 3.0.1

## 3.0.1.1

### 功能优化

连接池 DBConnectionPool 和 session 的 `run` 方法中的参数 *parallelism*
的默认值由 2 修改为 64。

## 3.0.1.0

### 新增功能

- `Database.createTable` 和
  `Database.createPartitionedTable` 新增参数
  *primaryKey* 和 *indexes*，以支持主键引擎下的数据表。

### 功能优化

- 支持对第三方库的非正式版本进行正确校验。
- 支持写入 Decimal 时自动对齐精度。
- 优化 Table 类调用 append 方法的执行效率。
- 增加版本依赖限制提示：暂不支持 NumPy 2.0。
