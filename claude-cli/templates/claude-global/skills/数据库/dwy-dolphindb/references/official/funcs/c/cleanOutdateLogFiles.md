# cleanOutdateLogFiles

## 语法

`cleanOutdateLogFiles([retentionTime=30])`

## 详情

手动触发超过 *retentionTime* 时间的系统日志的清理。

## 参数

**retentionTime** 系统日志的保留时间，默认是 30（单位：天）。

## 返回值

无。
