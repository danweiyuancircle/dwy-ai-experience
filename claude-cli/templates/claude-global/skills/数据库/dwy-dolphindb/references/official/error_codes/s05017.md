# S05017

## 错误代码

S05017

## 报错信息

A table cannot contain columns with duplicate name: <xxx>.RefId: S05017

## 错误原因

若表中出现重复的列名，则会报该错误。

## 解决办法

根据报错查找重复的列名进行修改。
