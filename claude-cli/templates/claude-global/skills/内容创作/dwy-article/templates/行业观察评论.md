适用场景: 对某个 IT 新闻 / 趋势 / 热点的看法——新模型发布、大厂裁员、技术风向、政策变化等

# 行业观察评论模板

定位：就一个热点亮出**自己的判断**，用事实和经历支撑。别假装中立面面俱到，读者要的是你怎么看。

固定锚点，按顺序：

```
# 标题：一个观点或一个发问，带态度（不标题党、不震惊体）

[由头] 从具体的事件 / 新闻 / 数据切入，一两句交代清楚发生了什么。

[我的观点] 早早亮明你怎么看，别和稀泥。

[展开] 用事实、亲身经历、行业里的例子论证。可以分角度，敢有偏见。别堆「一方面…另一方面…」装客观。

[落点] 落到一个具体判断，或对读者的实际影响（这事跟你有什么关系、该怎么应对）。不空喊、不升华。
```
