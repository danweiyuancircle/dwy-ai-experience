适用场景: 推荐一个好用的工具 / 库 / 服务 / 软件，讲清楚它好在哪、自己怎么用
---

# 工具资源安利模板

定位：以**自己的真实使用**为底，安利一个东西。不是搬官网介绍，是说「我用了，值不值得你也上」。

固定锚点，按顺序：

```
# 标题：直接说推荐什么、解决什么（如「这个内网穿透工具，我用了半年」）

[由头] 1-2 句：你之前被什么问题烦着，怎么发现这东西的。

## 它是什么
一句话说清它干嘛、解决什么痛点。别堆官网那套介绍。

## 我怎么用的
真实的使用场景 + 关键操作 / 配置（按需给命令或标注截图位）。说你自己的用法，不是复述文档。

## 好在哪、差在哪
敢说优点也敢说短板，别只夸。跟你用过的同类比一句。

[落点] 适不适合你：什么人 / 什么场景值得上，什么情况别用。附上链接位。
```
