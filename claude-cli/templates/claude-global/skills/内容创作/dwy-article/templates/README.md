# 文章模板目录

这里每个 `.md` 是一个文章类型的固定骨架。写作时 SKILL.md 会让模型扫这个目录、按文件名 + `适用场景` 挑一个读进来用。

## 怎么加一个新模板

往这个目录丢一个 `.md` 文件就行，**SKILL.md 不用改**。

### 文件格式

````
---
适用场景: 一句话说清什么内容用这个模板（写作时靠这句来匹配）
---

# XX 模板

定位：一句话，这类文章的写法重心是什么。

固定锚点，按顺序：

```
# 标题：……
[锚点1] ……
## 锚点2
……
[落点] ……
```
````

### 两条要求

1. **文件名**用能一眼看懂的中文类型名（如 `项目复盘.md`）——写作时先靠文件名挑模板。
2. 顶部 **`适用场景`** 写清楚——文件名撞车或拿不准时靠它区分。

### 边界

- 骨架里的锚点会成为文章的固定栏目（栏目感 = 个人辨识度）。
- 模板只管**结构**；语气、反 AI 味规则、输入输出约定统一在 SKILL.md，模板别重复写。
- 含步骤 / 命令 / 日志的类型（教程、排错），步骤区要可复现、工整，这不算 AI 味。

## 现有模板

| 文件 | 什么时候用 |
|---|---|
| 技术教程.md | 教别人搭起来 / 跑通某个东西，要能复现 |
| 个人感悟.md | 分享一个想明白的判断 / 观点 |
| 工具资源安利.md | 推荐一个好用的工具 / 库 / 服务 |
| 项目复盘.md | 做完一个项目 / 功能的经验总结 |
| 踩坑排错实录.md | 一次具体 bug / 故障的排查全过程 |
| 行业观察评论.md | 对某个 IT 新闻 / 趋势 / 热点的看法 |
| 方案选型对比.md | 几个方案里选一个，给对比和「我选谁、为什么」 |
| 概念科普.md | 一文搞懂某个概念 / 术语，讲清不教操作 |

> 这张表是给人看的索引，不影响选模板逻辑——加新模板可以顺手补一行，忘了也不影响功能。
