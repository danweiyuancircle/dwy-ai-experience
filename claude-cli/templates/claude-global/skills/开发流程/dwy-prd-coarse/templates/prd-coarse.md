# <产品名> · 粗 PRD

> 粗粒度，功能级。定「做什么、给谁、为什么、卖多少钱」，**不下到页面级**（页面级是细 PRD 的事）。每块都和用户分段敲定过、综合了市场分析。

## 产品定位

<一句话说清这是什么、解决谁的什么问题。结合市场分析的市场空位和竞品差异。例：给独立开发者的「单文件部署的轻量监控面板」，主打装起来五分钟、不依赖数据库。>

## 产品哲学

<这产品坚持什么、拒绝什么。3-5 条原则，每条一句。这是后面所有取舍的判据。例：① 默认零配置能跑 ② 数据本地优先 ③ 不做社交/不做会员等级。>

## 目标人群（画像）

<谁会用、什么场景下用、现在用什么替代。具体到能想象出一个真人，别写「所有需要 X 的人」。>

| 维度 | 内容 |
|---|---|
| 主画像 | <身份 + 一句话场景> |
| 次画像 | <可选> |
| 现在怎么解决 | <替代方案：手动 / 竞品 / 不解决> |
| 切入的痛点 | <最痛的那一个> |

## 定价策略
