# dwy-prd-detailed · 细 PRD（页面级）

对着高保真原型**逐页**写到**页面级**的 PRD。颗粒度要细到开发能照着写代码：每个页面有哪些元素、每条文案的字数上限和行数、每种状态、每个输入的长度上限、每个边界和跳转。这是开发的蓝本，空一处后面就要返工一次。

## 运行模式

上下文自适应，两种调用方式：

- **单独调用（默认）**：用户直接让你写细 PRD。从用户给的原型/页面或描述起步；产物落 `./prd-detailed.md` 或用户指定位置；**不读写 STATE.md、不依赖 `docs/0to1/`**。做完跑下方「门」即结束。
- **流水线调用**：`dwy-0to1` 调用，指令含「流水线模式」+ 前序产物路径（粗 PRD + 高保真原型目录）+ 落盘路径（如 `docs/0to1/05-prd-detailed.md`）。**STATE 记账由 dwy-0to1 负责，本 skill 不碰 STATE.md**。

## 输入（对着原型逐页写）

- **逐页打开高保真原型的每个 HTML** — 细 PRD 一页对一页地写，原型画了什么就写什么。原型是事实依据，**不对着原型 = 空对空，禁止**。
- 读粗 PRD（功能规则总纲）。
- 确认目标端，输入约束按端定（移动端键盘、桌面粘贴等）。
- 单独模式：用户没给原型就先问清有没有原型/设计稿可对照；实在没有就基于用户描述的页面逐页写，但要提醒「没有原型底稿，状态/极端 case 容易漏」。

## 怎么做（具体步骤）

套 `templates/prd-detailed.md`，**每个页面一节**，每节写全这几块：

1. **页面名 + 用途 + 入口/出口** — 这页让用户干什么、从哪进来、各动作去哪。
2. **元素 & 区块清单** — 对着原型把每个区块、每个元素列全（顶栏、列表、按钮、计数器…），标清各自规则（如「正文空时发布按钮置灰」）。
3. **列表项文案约束** — 每条会展示用户内容的地方，定：**字数上限 / 行数 / 溢出处理**（折叠？`…` 截断？展开？）。对着原型里画的超长文本态定。
4. **各状态** — 空 / 加载中 / 错误 / 无数据 / 无权限 / 超长 / 极端数据，每种写清表现。原型已画全，这里逐一文字化。
5. **输入校验（长度上限，前后端双层）** — 见下方专节，**这是硬规范**。
6. **交互 & 跳转** — 点什么去哪、二次确认、成功后路由。动效在这里用文字描述（原型没做动画）。
7. **边界** — 零结果、网络失败、超长、并发、空输入……每个都写清怎么处理。

## 特别提醒：所有用户输入必须限长（前端 + 后端双层）

dwy 全局规范硬要求——**凡接收用户输入的地方都要限长，前端即时反馈 + 后端防绕过，缺一不可**。细 PRD 里每个输入框 / textarea / 列表 / 分页都要写清：

| 位置 | 必须写明 |
|---|---|
| `input` / `textarea` / 富文本 | 字数上限（前端 `maxlength` + schema 兜底防粘贴绕过；后端再校验返回 422） |
| 列表项展示用户内容 | 字数上限 + 行数 + 溢出处理 |
| 分页 | `page_size` 默认值 + **上限**（防 DoS） |
| 文件 / 图片上传 | 数量上限 + 单个大小上限 + **图片额外校验像素尺寸**（防 decompression bomb） |
| Query / Path / Header | 长度上限 |

按业务语义定数：用户名几十字符、描述几百、正文几千、图片几 MB。**禁止任一字段无上限就过门。**

## 产物

落盘细 PRD（单独默认 `./prd-detailed.md`；流水线按编排器给的路径）。套 `templates/prd-detailed.md`（含一个填好的示例页 + 空白页模板）。frontmatter：

```
---
status: done
updated: <date +%Y-%m-%d>
---
```

成稿要件：原型里每个页面都有对应一节；每页七块齐全；每个输入都有前后端双层长度上限；每页的状态覆盖空/加载/错误/超长。落盘后**逐页核对原型**——原型有的页面 PRD 是否都写了、是否有输入漏写上限，再声称完成（先验证再声称）。

## 门（过门确认）

用 `AskUserQuestion` 把细 PRD 摆给用户：
- 摆什么：页面清单（与原型对齐）、关键约束（各输入长度上限、各列表折叠规则）、状态覆盖情况。
- 问什么：「细 PRD 这样定够细吗？通过 / 哪页要补 / 哪个约束要调？」

要改就改，直到用户确认。

## 边界 / 禁止

- **禁止脱离原型空写**——一页对一页，原型是事实依据。
- **禁止颗粒度停在功能级**——必须到页面级：具体元素、具体字数、具体行数、具体状态。
- **禁止任一用户输入无长度上限**（前端 + 后端双层），分页无 `page_size` 上限，图片不校验像素——违反 dwy 全局硬规范。
- **禁止漏状态**——空/加载/错误/超长/极端，每页都要覆盖到。
