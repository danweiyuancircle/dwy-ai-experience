## 示例（填好的样板，照这个颗粒度写每一版）

### v1：能写能看的笔记闭环

- **目标**：用户能新建、编辑、查看、删除笔记，一条完整可用闭环。
- **包含功能**（对应细 PRD 页面 / 功能）：
  - 笔记列表页（PRD 页面 1）：列表展示、空态、下拉刷新
  - 新建 / 编辑页（PRD 页面 2）：标题 + 正文输入（含前后端长度上限）、保存
  - 删除（PRD 页面 1 的滑动删除 + 二次确认）
- **依赖前序版本**：无（首版）。
- **验收标准**：
  - [ ] 新建一条笔记 → 列表出现该笔记
  - [ ] 编辑后 → 列表与详情内容同步更新
  - [ ] 删除 + 确认 → 列表移除该笔记
  - [ ] 正文超 5000 字 → 前端截断 + 提示，后端拒绝返回 422
  - [ ] 全量测试通过、构建 exit 0

### v2：搜索 + 标签

- **目标**：笔记多起来后能快速找到。
- **包含功能**（对应细 PRD 页面 / 功能）：
  - 搜索页（PRD 页面 3）：关键词搜索、结果高亮、零结果态
  - 标签（PRD 页面 2 的标签选择 + 页面 1 的标签筛选）
- **依赖前序版本**：v1（依赖 v1 已落地的笔记表结构与列表页）。
- **验收标准**：
  - [ ] 输入关键词 → 匹配的笔记按相关度返回，命中词高亮
  - [ ] 无匹配 → 显示零结果态文案
  - [ ] 给笔记打标签 → 列表可按标签筛选
  - [ ] 全量测试通过、构建 exit 0
